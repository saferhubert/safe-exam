## 第一节 安全生产监督管理

<h3 id="s1">1.1 三种安全生产监督管理体制</h3>

| 体制 | 内容 |
|---|---|
| **综合监管与行业监管** | **应急管理部门**是**综合监管部门**；<br/>**行业监管部门**包括：交通运输部（交通、铁路、民航）、水利部（水利工程）、住房和城乡建设部（建筑工程）、工业和信息化部（国防工业、邮电）、文化和旅游（旅游）、市场监管（**特种设备**）等 |
| **国家监察与地方监管** | 针对**危险性较高的特殊领域**，专门建立国家监察机制 |
| **政府监督与其他监督** | **政府监督**：应急管理部门和其他负有安全生产监督管理职责部门的监督、监察部门的监督<br/>**其他监督**：安全技术/管理服务机构、社会公众、工会、新闻媒体、居民委员会、村民委员会等组织的监督 |

<Callout type="tip">

**「国家监察与地方监管」的三个典型例子（易考）：**

1. **矿山**：国家建立**垂直管理**的矿山安全监察机构。国家设立**国家矿山安全监察局**，产矿地区设省级局，省级局设若干监察处。**人、财、物全部由中央负责**，避免受地方政府干扰。同时地方政府行使**地方监管**权。
2. **水上交通安全**（交通部海事局）：一方面设**垂直监管**机构，另一方面有些水上监管机构行政上归**地方政府**领导、业务上归**海事局**指导 → **垂直与分级相结合**
3. **特种设备**：实行**省以下垂直管理**体制

**记忆点**：矿山 = 纯垂直；水上 = 垂直与分级结合；特种设备 = 省以下垂直。

</Callout>

<h3>1.2 行政处罚的程序要求</h3>

**（1）行政处罚的种类（6 类）：**

1. 警告、通报批评
2. 罚款、没收违法所得、没收非法财物、没收非法开采出的煤炭以及采掘设备
3. 暂扣或者吊销有关许可证件，暂停或者撤销有关执业资格、岗位证书，降低有关资质等级
4. 限制开展生产经营活动、责令停止建设、责令停产停业整顿、责令停产停业、责令关闭、限制从业
5. **行政拘留**
6. 安全生产法律、行政法规规定的其他行政处罚

**（2）安全生产行政执法要点：**

| 项目 | 要求 |
|---|---|
| 调查取证 | 执法人员**不得少于 2 人**，并出示有效的执法证件表明身份 |
| 现场处理（能立即排除） | 责令**立即排除** |
| 现场处理（重大隐患且无法保证安全） | 责令**从危险区域撤出作业人员**，并责令**暂时停产停业、停止建设、停止施工或停止使用**相关设施设备，**限期排除隐患** |
| **简易程序** | 违法事实确凿并有法定依据，对**个人处以 200 元以下**罚款、对**生产经营单位处以 3000 元以下**罚款或警告的，可**当场**作出行政处罚决定 |
| **立案程序** | 对确需立即查处的违法行为，可**先行调查取证**，并在 **5 日内补办**立案手续 |

<Callout type="tip">

**简易程序金额口诀：个人 200，单位 3000**

（对个人 200 元以下 / 对单位 3000 元以下 + 警告 → 可当场处罚）

</Callout>

<h3>1.3 安全生产监督管理的方式</h3>

| 阶段 | 内容 |
|---|---|
| **事前监督管理** | ①有关**安全生产许可事项的审批（证书）**<br/>②**三同时**审查 |
| **事中监督管理** | 重点是**作业场所的监督检查**：<br/>①**行为监管**：制度、意识、行为<br/>②**技术监管**："三同时"监督检查、设备、设施、场所、劳保用品 |
| **事后监督管理** | ①**应急救援**<br/>②**事故处理** |

<Callout type="tip">

**阶段归属速记：**

- **事前** = 发证 + 三同时审查（**准入**）
- **事中** = 作业场所监督检查（**行为 + 技术**）
- **事后** = 应急救援 + 事故处理（**收尾**）

</Callout>
