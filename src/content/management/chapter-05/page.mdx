## 第一节 事故应急管理理论框架

<h3 id="s1">1.1 应急管理的四个阶段</h3>

| 阶段 | 内容 |
|---|---|
| **预防** | 防止事故发生，有**两层含义**：<br/>（1）通过**安全管理和安全技术**等手段，尽可能防止事故发生<br/>（2）在**假定事故必然发生**的前提下，通过预先采取的预防措施，达到**降低或减缓事故的影响或后果的严重程度** |
| **准备** | （1）为有效应对突发事件而**事先采取的各种措施的总称**，包括意识、组织、机制、预案、队伍、资源、培训演练等；**应急准备工作涵盖了应急管理工作的全过程**<br/>（2）包含：应急预案体系、风险评估与防范、救援队伍、应急物资储备、应急通信保障、培训、演练、捐赠、保险、科技等 |
| **响应** | 突发事件发生**以后**所进行的各种**紧急处置和救援**工作<br/>包括：组织营救、控制危险源、抢修公共设施、限制相关场所、启用应急救援物资、开展生态环境应急监测、采取措施防止**次生、衍生事件**等 |
| **恢复** | 突发事件的威胁和危害得到控制或消除后所采取的处置工作<br/>**短期恢复**：向受灾人员提供食品、避难所、安全保障和医疗卫生等基本服务<br/>**长期恢复**：重点是**经济、社会、环境和生活的恢复**，包括重建被毁的设施和房屋、重新规划和建设受影响区域等 |

<Callout type="tip">

**四阶段口诀：预防 → 准备 → 响应 → 恢复**

**关键提醒**：「准备」涵盖**应急管理工作的全过程**（不只是事前）——这是易考的细节。

</Callout>

## 第二节 应急预案体系与内容

<h3 id="s2">2.1 三类应急预案</h3>

| 类型 | 内涵 | 关键点 |
|---|---|---|
| **综合应急预案** | 为应对**各种**生产安全事故而制定的**综合性工作方案**，是本单位应对生产安全事故的**总体工作程序、措施和应急预案体系的总纲** | 体系**总纲** |
| **专项应急预案** | 为应对**某一种或几种类型**生产安全事故，或针对**重要生产设施、重大危险源、重大活动**防止事故而制定的**专项工作方案** | 强调**某种类型事故、重要设施、重大危险源、重大活动** |
| **现场处置方案** | 根据不同生产安全事故**类别**，针对**具体场所、装置或者设施**所制定的**应急处置措施** | 针对**具体场所/装置/设施** |

<Callout type="info">

**两个「可以不编」的特殊规定（易考）：**

1. **专项应急预案**与综合应急预案中的应急组织机构、应急响应程序**相近**时，**可不编写专项应急预案**，相应的应急处置措施**并入综合应急预案**
2. 事故风险**单一、危险性小**的生产经营单位，**可只编制现场处置方案**

</Callout>

<h3>2.2 应急预案的内容（口诀必背）</h3>

<KeyPoint examWeight={3}>
**三个口诀（考试高频）：**
- **综合应急预案** = **总责响处保**（总则、应急组织机构及职责、应急响应、后期处置、应急保障）
- **专项应急预案** = **适责响处保**（适用范围、应急组织机构及职责、响应启动、处置措施、应急保障）
- **现场处置方案** = **风责处注**（事故风险描述、应急工作职责、应急处置、注意事项）
</KeyPoint>

**（1）综合应急预案内容：**

| 项目 | 内容 |
|---|---|
| **总则** | **适用范围**：说明预案适用范围<br/>**响应分级**：依据事故危害程度、影响范围和单位控制事态的能力，对应急响应进行分级。**响应分级不必照搬事故分级** |
| **应急组织机构及职责** | 明确应急组织形式及构成单位的应急处置职责；可设置工作小组，小组构成、职责分工及行动任务应以**工作方案**形式作为**附件** |
| **应急响应** | **信息报告**：接报（明确应急值守电话、事故信息接收、内部通报程序、方式和责任人）；处置与研判<br/>**预警**：预警启动、响应准备、预警解除<br/>**响应启动**：确定响应级别，明确程序性工作（应急会议召开、信息上报、资源协调、信息公开、后勤及财力保障）<br/>**应急处置**：警戒疏散、人员搜救、医疗救治、现场监测、技术支持、工程抢险及环境保护措施，并明确人员防护要求<br/>**应急支援**：明确向外部救援力量请求支援的程序、联动程序及指挥关系<br/>**响应终止**：明确响应终止的基本条件、要求和责任人 |
| **后期处置** | 明确**污染物处理、生产秩序恢复、人员安置**方面的内容 |
| **应急保障** | **通信与信息**保障、**应急队伍**保障（专家、专兼职应急救援队伍及协议应急救援队伍）、**物资装备**保障（类型、数量、性能、存放位置、运输及使用条件、更新及补充时限、管理责任人及联系方式，并**建立台账**）、**其他**保障（经费、交通运输、治安、技术、医疗、后勤保障等） |

**（2）专项应急预案内容（适责响处保）：**
适用范围 → 应急组织机构及职责 → 响应启动 → 处置措施 → 应急保障

**（3）现场处置方案内容（风责处注）：**

| 项目 | 内容 |
|---|---|
| **事故风险描述** | 7 项：①风险类型 ②可能发生的事故类型 ③事故发生的**区域、地点或装置名称** ④事故发生的**可能时间段或概率** ⑤事故的**危害严重程度及其影响范围** ⑥事故前**可能出现的征兆** ⑦事故可能引发的**次生、衍生事故**等 |
| **应急工作职责** | 明确应急组织分工和职责 |
| **应急处置** | ①**应急处置程序** ②**现场应急处置措施**（人员救护、工艺操作、事故控制、消防、现场恢复）③明确报警负责人、报警电话及上级管理部门、相关应急救援单位联络方式和联系人，事故报告基本要求和内容 |
| **注意事项** | 包括**人员防护和自救互救、装备使用、现场安全**等 |

<h3>2.3 应急处置卡</h3>

依据**《生产安全事故应急预案管理办法》（应急管理部令第 2 号）第十九条**：生产经营单位应当在编制应急预案的基础上，针对**工作场所、岗位的特点**，编制**简明、实用、有效**的应急处置卡。

应急处置卡应当规定**重点岗位、人员**的应急处置程序和措施，以及相关联络人员和联系方式，便于从业人员携带。

**分类（依据《生产经营单位生产安全事故应急处置卡编制指南》YJ/T 32）：**

| 类型 | 主要内容 |
|---|---|
| **应急管理岗位** | ①明确应急管理岗位人员在**领导指挥、信息报告、应急处置**过程中采取的具体行动步骤<br/>②列出需要的应急救援队伍、专家、物资装备、医疗资源、交通运输、避难场所等应急资源<br/>③列出主要联系的部门、机构或人员及联系方式<br/>④根据紧急疏散需要，编制**疏散逃生应急处置卡**<br/>⑤其他注意事项 |
| **基层操作岗位** | ①简要描述岗位**主要风险类型及事故情景**<br/>②列出该岗位在**信息报告、应急响应和处置措施**方面的具体处置步骤，明确每个步骤的**责任人**<br/>③列出需要的人力、设备、物资等应急资源<br/>④列出「**谁预警、谁组织、谁处置、谁撤离**」等具体处置步骤，宜标绘**紧急避险路线图**<br/>⑤其他注意事项<br/>⑥根据需要，附上**装置工艺流程图** |

## 第三节 应急预案编制程序与演练

<h3 id="s3">3.1 应急预案编制程序（8 个步骤）</h3>

| 步骤 | 内容 |
|---|---|
| **1. 成立预案编制组** | 以单位**有关负责人为组长**，单位相关部门人员（生产、技术、设备、安全、行政、人事、财务）参加<br/>应**邀请相关救援队伍以及周边相关企业、单位或社区代表**参加 |
| **2. 资料收集** | ①适用的法律规范及技术标准 ②企业周边环境资料 ③企业现场布置情况 ④工艺流程及风险评估 ⑤事故隐患 ⑥属地政府及周边企业、单位应急预案 |
| **3. 风险评估** | ①辨识存在的危险有害因素，确定可能发生的事故类别<br/>②分析各种事故类别发生的**可能性、危害后果和影响范围**<br/>③评估确定相应事故类别的**风险等级** |
| **4. 应急资源调查** | ①本单位可调用的应急队伍、装备、物资、场所<br/>②可采取的监测、监控、报警手段<br/>③上级单位、当地政府及周边企业可提供的应急资源<br/>④可协调使用的医疗、消防、专业抢险救援机构及其他社会化应急救援力量 |
| **5. 应急预案编制** | 遵循**以人为本、依法依规、符合实际、注重实效**的原则，以**应急处置**为核心，体现**自救互救和先期处置**的特点，做到职责明确、程序规范、措施科学，尽可能**简明化、图表化、流程化** |
| **6. 桌面推演** | 可采取**桌面演练**形式，模拟事故应对过程，逐步分析讨论并形成记录，检验预案可行性并进一步完善 |
| **7. 应急预案评审** | 见下表 |
| **8. 批准实施** | 通过评审的应急预案，由生产经营单位**主要负责人签发实施**（本单位内公布，发放到有关部门、岗位和救援队伍，**高危行业 20 个工作日内安监部门备案**） |

<KeyPoint examWeight={3}>
**评审环节的三个关键数字/要求：**

1. **表决时，应有不少于出席会议专家人数的三分之二同意方为通过**
2. 评审会议应形成**评审意见（经评审组组长签字）**，附参加评审会议的**专家签字表**
3. **评审专家不得与评审单位有利害关系**

**评审程序三步：** 评审准备 → 组织评审 → 修改完善（表决不通过的，修改完善后**按评审程序重新组织**专家评审）
</KeyPoint>

<h3 id="s4">3.2 应急演练的内容（11 项）</h3>

| 内容 | 说明 |
|---|---|
| **预警与报告** | 向相关部门或人员发出预警信息，并向有关部门和人员报告事故情况 |
| **指挥与协调** | 成立应急指挥部，调集应急救援队伍和相关资源，开展应急救援行动 |
| **应急通信** | 在应急救援相关部门或人员之间进行音频、视频信号或数据信息互通 |
| **事故监测** | 对事故现场进行观察、分析或测定，确定事故**严重程度、影响范围和变化趋势**等 |
| **警戒与管制** | 建立应急处置现场警戒区域，实行**交通管制**，维护现场秩序 |
| **疏散与安置** | 对事故可能波及范围内的相关人员进行疏散、转移和安置 |
| **医疗卫生** | 调集医疗卫生专家和卫生应急队伍开展紧急医学救援，并开展**卫生监测和防疫**工作 |
| **现场处置** | 按照相关应急预案和现场指挥部要求对事故现场进行控制和处理 |
| **社会沟通** | 召开**新闻发布会或事故情况通报会**，通报事故有关情况 |
| **后期处置** | 应急处置结束后，开展事故**损失评估、原因调查、现场清理和相关善后**工作 |
| **其他** | 根据相关行业（领域）安全生产特点开展其他应急工作 |

<Callout type="tip">

**11 项演练内容速记：**

**预警报告 → 指挥协调 → 应急通信 → 事故监测 → 警戒管制 → 疏散安置 → 医疗卫生 → 现场处置 → 社会沟通 → 后期处置 → 其他**

**分组记忆（4 组）：**
- **信息组**：预警与报告、应急通信、社会沟通
- **指挥组**：指挥与协调
- **现场组**：事故监测、警戒与管制、疏散与安置、现场处置、医疗卫生
- **收尾组**：后期处置、其他

</Callout>
