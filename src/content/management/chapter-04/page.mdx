## 第一节 职业病危害因素分类与识别

<h3 id="s1">1.1 按来源分类</h3>

| 来源 | 类别 | 内容 |
|---|---|---|
| **生产过程中产生** | **化学因素** | **生产性粉尘**：矽尘、煤尘、石棉尘、电焊烟尘等<br/>**化学有毒物质**：铅、汞、锰、苯、一氧化碳、硫化氢、甲醛、甲醇等 |
| | **物理因素** | 异常气象条件（高温、高湿、低温）、异常气压、**噪声、振动、辐射**等 |
| | **生物因素** | 附着于皮毛上的**炭疽杆菌**、甘蔗渣上的**真菌**、医务工作者接触的**生物传染性病原物**等 |
| **劳动过程中** | — | ①劳动组织和制度不合理、作息制度不合理<br/>②精神性职业紧张<br/>③劳动强度过大或生产定额不当<br/>④个别器官或系统过度紧张（如视力紧张）<br/>⑤长时间不良体位或使用不合理的工具 |
| **生产环境中** | — | ①**自然环境**中的因素（如炎热季节的太阳辐射）<br/>②作业场所**建筑卫生学设计缺陷**（如照明不良、换气不足） |

<h3>1.2 按《职业病危害因素分类目录》分类</h3>

| 类别 | 种数 | 举例 |
|---|---|---|
| **粉尘** | **52 种** | 矽尘、煤尘、石墨粉尘、炭黑粉尘、石棉粉尘、滑石粉尘、水泥粉尘、云母粉尘、陶土粉尘、铝尘、电焊烟尘、铸造粉尘等 |
| **化学因素** | **375 种** | 铅及其化合物（**不包括四乙基铅**）、汞、锰、镉、铍、铊、钡、钒、磷及其化合物（磷化氢、磷化锌、磷化铝，**有机磷单列**）、砷及其化合物（**砷化氢单列**）、铀及其化合物等 |
| **物理因素** | **15 种** | 噪声、高温、低气压、高气压、高原低氧、振动、激光、低温、微波、紫外线、红外线、工频电磁场、高频电磁场、超高频电磁场等 |
| **放射性因素** | **8 种** | 密封放射源产生的电离辐射（γ、中子等射线）、非密封放射性物质（α、β、γ射线或中子）、X 射线装置（含 CT 机）、加速器、中子发生器、**氡及其短寿命子体**（限于矿工高氡暴露）、铀及其化合物等<br/>**总结：产生 α、β、γ 射线、X 射线、中子射线等** |
| **生物因素** | **6 种** | **艾滋病病毒**（限于医疗卫生人员及人民警察）、布鲁氏菌、伯氏疏螺旋体、森林脑炎病毒、炭疽芽孢杆菌等 |
| **其他因素** | **3 种** | **金属烟**、**井下不良作业条件**（限于井下工人）、**刮研作业**（限于手工刮研作业人员） |

<Callout type="tip">

**种数速记：尘 52、化 375、物 15、放 8、生 6、其他 3**

**高频易错点：**
- 铅及其化合物**不包括四乙基铅**
- **有机磷单列**（不归入磷及其化合物）
- **砷化氢单列**（不归入砷及其化合物）
- **艾滋病病毒**仅限**医疗卫生人员及人民警察**
- 其他因素只有 **3 种**：金属烟、井下不良作业条件、刮研作业

</Callout>

<h3>1.3 职业中毒</h3>

**生产性毒物的存在形态：**

| 存在形态 | 产生原因 | 举例 |
|---|---|---|
| **气态** | 常温下是气体 | 氯气、一氧化碳 |
| **蒸气** | 常温下是液体挥发 | 苯、丙酮 |
| | 常温下是固体有挥发性，特别在高温工作场所 | 酚、三氧化二砷 |
| **气溶胶·雾** | 液态分散性气溶胶（常温下是液体，加热分散） | 电镀铬 |
| | 液态凝集性气溶胶（沸腾溅出的液雾） | 碱液加热浓缩 |
| | 喷洒雾滴 | 农药喷洒 |
| **气溶胶·烟** | 固态凝集性气溶胶（金属熔化时蒸气，或蒸气在空气中被氧化） | **铅烟、铜烟** |
| **气溶胶·尘** | 固态分散性气溶胶（物理性加工过程中以粉尘形式逸散） | 生产性粉尘 |

<Callout type="info">

**三个必记结论：**

1. **侵入人体的途径**：**吸入、经皮吸收、食入**（三条）
2. **职业中毒类型**：**急性中毒、慢性中毒、亚急性中毒**（三类）
3. **职业接触生产性毒物的机会**：**正常生产过程、检修与抢修、意外事故**（三种）

</Callout>

<h3>1.4 物理性职业病危害因素导致的职业病</h3>

| 因素 | 描述 | 导致的职业病 |
|---|---|---|
| **噪声** | 包括**空气动力噪声、机械噪声和电磁噪声** | **噪声聋** |
| **振动** | 使用锤打工具、手持转动工具、固定轮转工具作业，驾驶交通运输工具或农业机械作业 | **手臂振动病** |
| **非电离辐射·射频** | 不会导致组织器官器质性损伤，具有**可逆性**特征 | — |
| **非电离辐射·微波** | 非致热效应主要表现在**神经、分泌和心血管系统** | — |
| **非电离辐射·红外线** | 炼钢工、轧钢工、锻造工、焊接工可接触 | **白内障** |
| **非电离辐射·紫外线** | 辐射源：冶炼炉、电焊、氧乙炔气焊、氩弧焊、等离子焊接等 | **电光性眼炎** |
| **非电离辐射·激光** | 可突然出现眩光感、视力模糊等 | — |
| **电离辐射** | 天然/人工放射性核素、X 线机等 | 全身性放射性疾病（急、慢性放射病）、局部放射性疾病（急慢性放射性皮炎、放射性白内障）、放射所致远期损伤（**放射所致白血病**） |
| **异常气象条件** | 温度、湿度、风速、热辐射、气压 | **中暑、减压病、高原病** |

<Callout type="tip">

**「因素 → 疾病」速记对照（高频）：**

- **噪声** → **噪声聋**
- **振动** → **手臂振动病**
- **红外线** → **白内障**（想想炼钢炉前的高温辐射）
- **紫外线** → **电光性眼炎**（电焊「打眼」）
- **异常气象** → 中暑、减压病、高原病

**易混提示**：紫外线导致**电光性眼炎**，红外线导致**白内障**——不要搞反。

</Callout>

<Callout type="tip">

**「致癌物 → 靶器官」考点配对：**

- **苯** → **白血病**
- **氯乙烯** → **肝血管瘤**
- **石棉 / 毛沸石** → **肺 + 胸膜间皮瘤**
- **联苯胺 / 4-氨基联苯 / 1-萘胺** → **膀胱**（泌尿系统）
- **氯甲醚 / 二氯甲醚 / 六价铬** → **肺**
- **沥青** → **皮肤**

**记忆技巧**：苯在**骨髓造血**里积累 → 白血病；氯乙烯做塑料，**肝脏**代谢 → 肝血管瘤。

## 第二节 职业病危害控制与管理

<h3 id="s2">2.1 职业危害控制的三类措施</h3>

| 措施 | 内容 |
|---|---|
| **工程技术措施** | 应用工程技术的措施和手段（**密闭、通风、冷却、隔离**等），控制生产工艺过程中产生或存在的职业危害因素的**浓度或强度**，使作业环境中有害因素的浓度或强度降至国家职业卫生标准容许的范围内 |
| **个体防护措施** | 针对不同类型的职业病危害因素，选用合适的**防尘、防毒或防噪声**等个体防护用品 |
| **组织管理措施** | 建立、健全职业病危害预防控制规章制度，确保有关要素的良好与有效运行 |

**工程技术措施的具体应用：**

- **粉尘** → **湿式作业** 或 **密闭抽风除尘**
- **化学毒物** → **全面通风、局部送风、排出气体净化**
- **噪声** → **隔离降噪、吸声**技术措施

<Callout type="tip">

**三类措施的记忆线索：工程 → 个体 → 管理**

- **工程**：动设备/工艺（治本，管「浓度和强度」）
- **个体**：给**人**穿装备（兜底）
- **管理**：定**制度**（保障运行）

</Callout>

<h3>2.2 劳动过程中的防护和管理</h3>

**（1）材料和设备管理：**
- 可能产生职业病危害的设备有**中文说明书**；在设备**醒目位置**设置**警示标识和中文警示说明**
- **不转嫁**职业病危害的作业给不具备防护条件的单位和个人；**不接受**不具备防护条件的有职业病危害的作业
- 有毒物品的包装有**警示标识和中文警示说明**（所有有害材料都要有标识）

**（2）作业场所管理：**

| 场所类型 | 要求 |
|---|---|
| 放射作业场所 | 应设**报警装置**；放射性同位素的运输、储存应配置**报警装置** |
| 一般有毒作业 | 设置**黄色**区域警示线 |
| **高毒**作业场所 | 设**红色**区域警示线 |
| 高毒作业 | 应设**淋浴间、更衣室、物品存放专用间**，还应为**女工设冲洗间** |

<Callout type="tip">

**警示线颜色口诀：一般有毒黄，高毒红**

（与安全色逻辑一致：黄=警告，红=禁止/高危）

</Callout>

**（3）作业环境职业病危害因素检测管理：**
设专人负责**日常检测**；按规定**定期检测与评价**；检测、评价结果存入**职业卫生档案**

**（4）防护设备设施和个人防护用品管理：**
台账齐全、配备齐全、设施有效；有个人防护用品计划并组织实现；按标准配备符合防治要求的个人防护用品；有**发放登记记录**；及时维护、定期检测

**（5）履行告知义务（原则：公开透明）：**
- 在**醒目位置公布**职业病防治规章制度
- 签订劳动合同时，在合同中**载明可能产生的职业病危害及其后果**，载明防护措施和待遇
- 公布操作规程、应急救援措施、作业场所危害因素**监测和评价结果**
- **告知劳动者职业病健康体检结果**
- 对于患职业病或**职业禁忌证**的劳动者，企业应**告知本人**

<h3>2.3 职业健康监护</h3>

<KeyPoint examWeight={3}>
**职业健康监护必须由专职人员负责**，并建立、健全**职业健康监护档案**。

**档案包括**：劳动者的**职业史、职业病危害接触史、职业健康检查结果和职业病诊疗**等有关个人健康资料。
</KeyPoint>

**职业健康检查的三个阶段：**

| 阶段 | 目的与要求 |
|---|---|
| **上岗前** | ①目的是发现**有无职业禁忌症**，建立接触职业病危害因素劳动者的**基础健康档案**<br/>②属于**强制性**职业健康检查，从事有害作业前完成<br/>③人员包括：拟从事接触职业病危害因素的作业人员（**新录用与转岗**）以及拟从事**特殊健康要求作业**的人员（如高处作业、电工作业、职业机动车驾驶作业等） |
| **在岗期间** | ①目的：**早期发现**职业病或疑似职业病以及危害因素引起的健康损害；**及时发现职业禁忌症**；评价工作场所危害因素的**控制效果**<br/>②应**定期**开展，周期根据危害因素性质、浓度或强度、目标疾病的**潜伏期或潜隐期**和防护措施等因素决定 |
| **离岗时** | ①目的是确定其在**停止接触职业病危害因素时的健康状况**<br/>②**离岗前 90 天内的**职业健康检查**可视为离岗检查**<br/>③从事职业病危害作业或岗位 **30 天内**离岗，且该岗位危害因素**低于职业接触限值**的，**免于**离岗时检查 |
| **离岗后** | 检查时间长短应根据有害因素致病的**流行病学及临床特点**、劳动者从事该作业的**时间长短**、工作场所有害因素的**浓度**等因素综合考虑确定 |
| **应急健康检查** | — |

<Callout type="tip">

**两个数字必背：**

- **离岗前 90 天内**的检查 → **可视为离岗检查**
- 从事危害作业 **30 天内**离岗 且 危害因素**低于职业接触限值** → **免于**离岗检查

**三阶段目的速记：**
- 上岗前 = 查**禁忌症**（建立基础档案）
- 在岗期间 = **早发现**（职业病/禁忌症）+ 评价控制效果
- 离岗时 = 确定**离岗时的健康状况**

</Callout>
