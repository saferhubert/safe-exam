## 第一节 统计图类型与统计指标

<h3 id="s1">1.1 统计图的类型与选用原则</h3>

| 类型 | 含义 | 选用原则 |
|---|---|---|
| **条图**（直条图） | 表示独立指标在不同阶段的情况，有两维或多维，图例位于**右上方**；表示**数值大小** | 比较**分类资料各类别数值大小** |
| **圆图 或 百分条图** | 描述百分比（构成比）的大小，用颜色或各种图形将不同比例表达出来 | 分析**事物内部各组成部分所占比重** |
| **线图** | 用线条的**升降**表示事物的发展变化趋势，主要用于**计量资料**，描述两个变量间关系 | 描述事物**随时间变化趋势**或描述两现象**相互变化趋势** |
| **半对数线图** | 纵轴用**对数尺度**，描述一组连续性资料的**变化速度及趋势** | 描述随时间变化趋势或两现象相互变化趋势 |
| **散点图** | 描述两种现象的相互关系的**密切程度和方向** | 描述**双变量**资料的相互关系的密切程度或方向 |
| **直方图** | — | 描述**连续性变量的频数分布** |
| **统计地图** | — | 描述某现象的数量在**地域上的分布** |

<Callout type="tip">

**选图口诀 —— 看「目的」选「图型」：**

- 比**大小**（各类别数值）→ **条图**
- 看**占比**（构成比）→ **圆图 / 百分条图**
- 看**趋势**（随时间变化）→ **线图**
- 看**变化速度**（速率差异大）→ **半对数线图**
- 看**两变量关系**（相关性）→ **散点图**
- 看**频数分布**（连续变量）→ **直方图**
- 看**地域分布** → **统计地图**

**高频易错**：线图看**趋势**，半对数线图看**变化速度**；条图比**大小**，直方图看**频数分布**。

</Callout>

<h3>1.2 事故统计指标体系</h3>

| 类型 | 含义 | 举例 |
|---|---|---|
| **绝对指标** | 反映伤亡事故全面情况的**绝对数值** | 事故起数、死亡人数、重伤人数、轻伤人数、直接经济损失、损失工作日<br/>→ **【数值】** |
| **相对指标** | 伤亡事故的**两个相联系的绝对指标之比**，表示事故的**比例关系** | 千人事故死亡率、千人事故受伤率、百万吨死亡率、万立方米死亡率<br/>→ **【比率】** |

<h3>1.3 常见事故指标计算公式</h3>

| 指标 | 计算方法 |
|---|---|
| **千人事故死亡率** | 死亡人数 ÷ 平均从业人员数 × 10³ |
| **千人事故受伤率** | 受伤人数 ÷ 平均从业人员数 × 10³ |
| **百万吨死亡率** | 死亡人数 ÷ 实际产量(t) × 10⁶ |
| **万立方米死亡率** | 死亡人数 ÷ 实际产量(m³) × 10⁴ |
| **亿元 GDP 死亡率** | 死亡人数 ÷ 国内生产总值(元) × 10⁸ |
| **百万工时死亡率** | 死亡人数 ÷ 实际总工时 × 10⁶ |
| **重大事故率** | 重大事故起数 ÷ 事故总起数 × 100% |
| **百万人火灾死亡率** | 火灾造成的死亡人数 ÷ 地区总人口 × 10⁶ |
| **万车死亡率** | 机动车造成的死亡人数 ÷ 机动车数 × 10⁴ |

<Callout type="tip">

**公式记忆要点：分母决定「率」的名称**

- **千人** → 分母是**平均从业人员数**，乘 10³
- **百万吨 / 万立方米** → 分母是**实际产量**，分别乘 10⁶ / 10⁴
- **亿元 GDP** → 分母是**国内生产总值**，乘 10⁸
- **百万工时** → 分母是**实际总工时**，乘 10⁶
- **重大事故率** → 是**起数之比**，× 100%

⚠️ **特别注意**：绝大多数指标的分母是「**单位平均从业人员**」，但**百万人火灾死亡率**的分母是「**地区平均人口**」——这是最容易考倒人的地方。

</Callout>

## 第二节 伤亡事故经济损失计算

<h3 id="s2">2.1 直接经济损失</h3>

<KeyPoint examWeight={3}>
**直接经济损失包括 5 类**（口诀：**人财救清事** —— 人才旧情事）：

1. **人身伤亡后所支出的费用**
2. **财产损失价值**
3. **事故应急救援费用**
4. **清理事故现场以及影响区域的费用**
5. **事务性费用**
</KeyPoint>

**各类明细：**

| 类别 | 具体内容 |
|---|---|
| **（1）人身伤亡后所支出的费用** | 医疗费、护理费、营养费、丧葬及抚恤费用、补助及救济费用、歇工工资或误工费、残疾赔偿金或死亡赔偿金 |
| **（2）财产损失价值** | 固定资产损失价值、存货损失价值、在建工程及工程物资损失价值、生物资产损失价值 |
| **（3）事故应急救援费用** | 救援人工费、救援物资费、救援设备费或设备使用费、救援保障费 |
| **（4）清理事故现场及影响区域费用** | 为恢复事故现场及影响区域、整理和清除残留物所支付的所有费用 |
| **（5）事务性费用** | 事故伤亡人员**亲属**在参与善后处理过程中产生的交通费、伙食费、住宿费 |

<h3>2.2 间接经济损失</h3>

| 序号 | 内容 |
|---|---|
| （1） | **停产、减产、停业、复产**损失价值 ★ |
| （2） | **工作损失价值**（常考计算） |
| （3） | **资源损失价值**：矿藏资源、森林资源、能源资源、景观资源等有形资源的损失价值 |
| （4） | **其他民事赔偿费**：因发生事故导致不能如期履行合同的赔偿费等 ★ |
| （5） | **事故罚款**（单位实际罚款额，**不含个人**）★ |
| （6） | **补充新从业人员的招收和培训费用** ★ |
| （7） | **事故调查费**：办公费、交通费、食宿费、差旅费、检测检验费、模拟实验费、技术鉴定费★、技术咨询费、技术服务费、制作视频费、文印费和聘请专家费★等 |
| （8） | **消除事故次生危害主动支出的费用**：为保护公私财产、人身安全而主动支出的处置费用；因事故造成的环境污染损害费用、污染治理费★ |
| （9） | **其他间接经济损失**：器官功能恢复训练所必要的康复费、适当的整容费、残疾器具费等；政府或公益机构支出的应急救援费★ |

<Callout type="tip">

**直接 vs 间接 的辨析锚点：**

- **直接** = 事故**当场/善后直接花的钱** → 医疗、赔偿、救援、清理、亲属差旅
- **间接** = 事故**带来的连锁损失** → 停产减产、罚款、合同违约、资源损失、调查费、康复整容、培训新人

**高频易错三连**：
1. **事故罚款** = **间接**损失（不是直接！）
2. **政府或公益机构支出的应急救援费** = **间接**损失（企业自己的救援费才是直接）
3. **亲属的交通食宿费** = **直接**损失（属于事务性费用）

</Callout>

<h3>2.3 工作损失价值计算</h3>

**公式：** VW = DL × M ÷ (S × D)

| 符号 | 含义 | 单位 |
|---|---|---|
| **VW** | 工作损失价值 | 万元 |
| **DL** | 事故的**总损失工作日数** | — |
| **M** | 生产经营单位**上年度利润总额** | 万元 |
| **S** | 生产经营单位**上年平均从业人员人数** | 人 |
| **D** | 生产经营单位**上年法定工作日数** | 工日 |

<Callout type="info">

**两个关键限定：**

1. **D（法定工作日数）**：题干一般会告知；**未告知则按 250 工作日**计算
2. 若生产经营单位**上年税利为零或负值**，则 **M 取最近为正值的年份的利润总额**

</Callout>
