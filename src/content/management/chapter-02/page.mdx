## 第一节 安全生产主体责任与规章制度

<h3 id="s1">1.1 生产经营单位的安全生产主体责任（7 类）</h3>

| 责任类别 | 内容要点 |
|---|---|
| **设备设施（或物质）保障责任**（物） | 具备安全生产条件；依法履行建设项目安全设施**"三同时"**规定；依法为从业人员提供**劳动防护用品**，并监督、教育其正确佩戴和使用<br/>（注意：**安全评价**属于**安全生产管理责任**；**劳动防护用品不能用金钱代替**） |
| **资金投入责任**（钱） | 按规定提取和使用**安全生产费用**，确保资金投入满足安全生产条件需要；按规定建立健全**安全生产责任保险**制度，依法为从业人员缴纳**工伤保险费**；保证**安全生产教育培训**的资金 |
| **机构设置和人员配备责任**（人） | 依法设置**安全生产管理机构**，配备**安全生产管理人员**；按规定委托和聘用**注册安全工程师**或注册安全助理工程师为其提供安全管理服务 |
| **规章制度制定责任**（制度） | 建立、健全安全生产责任制和各项规章制度、操作规程、应急救援预案并督促落实<br/>（注意：**获取法律法规**属于**安全生产管理责任**） |
| **安全教育培训责任**（教育） | 开展安全生产宣传教育；依法组织从业人员参加安全生产教育培训，取得相关上岗资格证书 |
| **安全生产管理责任**（管理） | 主动获取国家有关安全生产法律法规并贯彻落实；依法取得**安全生产许可**；定期组织开展**安全检查**；依法对安全生产设施、设备或项目进行**安全评价**；依法对**重大危险源**实施监控；及时消除**事故隐患**；**统一协调管理**承包、承租单位的安全生产工作 |
| **事故报告和应急救援责任**（应急） | 按规定**报告**生产安全事故，及时开展事故**抢险救援**，妥善处理事故**善后**工作 |

<Callout type="tip">

**七类责任速记：物、钱、人、制度、教育、管理、应急**

**两个高频易错归属（必记）：**
1. **安全评价** → 属于「**安全生产管理责任**」（不是设备设施保障责任）
2. **获取法律法规** → 属于「**安全生产管理责任**」（不是规章制度制定责任）
3. **劳动防护用品不能用金钱代替** → 提供防护用品属「设备设施保障责任」

</Callout>

<h3>1.2 安全生产规章制度的四大体系</h3>

按安全系统工程和人机工程原理，安全生产规章制度分为 **4 类**：**综合管理、人员管理、设备设施管理、环境管理**。

| 综合管理制度 | 人员制度（对象是人） | 设备设施制度（对象是设备） | 环境制度（环卫标志） |
|---|---|---|---|
| 目标、指标和总体原则 | 消防安全 | "三同时"制度 | 安全标志 |
| 安全生产责任制 | 风险分级管控和隐患排查治理双重预防 | 劳动防护用品发放使用和管理 | 作业环境 |
| 安全管理定期例行工作 | 交通安全 | 定期巡视检查 | 职业卫生 |
| 承发包工程 | 防灾减灾 | 安全工具器的使用 | — |
| 设施和费用 | 事故调查报告处理 | 定期维护检修 | — |
| 重大危险源 | 应急管理 | 定期检测、检验 | — |
| 危险物品使用 | 安全奖惩 | 安全操作规程 | — |
| 现场作业安全管理 | — | 职业健康检查 | — |

<Callout type="tip">

**四类体系的辨析锚点：**

- **综合管理** → 「**大局性**」制度（目标、责任制、承发包、重大危险源、危险物品、现场作业）
- **人员制度** → 一切针对「**人**」的（消防、交通、培训、防灾、应急、奖惩、事故调查）
- **设备设施** → 一切针对「**物**」的（三同时、防护用品、巡视、检修、检测检验、操作规程、职业健康检查）
- **环境制度** → 只涉及「**环境/卫生/标志**」（安全标志、作业环境、职业卫生）

</Callout>

<h3>1.3 规章制度的制定流程（8 步）</h3>

| 步骤 | 内容 |
|---|---|
| **1. 起草** | 由负责**安全生产管理部门或相关职能部门**负责起草。起草前应对**目的、适用范围、主管部门、解释部门及实施日期**等给予明确 |
| **2. 会签或公开征求意见** | 应通过正式渠道征得相关部门或员工的意见和建议。意见不能取得一致时，应由**分管领导**组织讨论。制定或修改有关安全生产的规章制度，**应当听取工会的意见** |
| **3. 审核** | ①由负责**法律事务的部门**进行**合规性审查**；②**专业技术性较强**的应邀请**相关专家**审核；③**安全奖惩等涉及全员性**的制度，应经过**职工代表大会或职工代表**审核 |
| **4. 签发** | **技术规程、安全操作规程**等技术性较强的，一般由**主管生产的领导或总工程师**签发；涉及**全局性的综合管理制度**应由**主要负责人**签发 |
| **5. 发布** | 采用固定的方式发布（**红头文件、内部办公网络**等）。发布范围应涵盖应执行的部门、人员。特殊制度还要正式送达并由接收人员**签字** |
| **6. 培训** | 新发布或修订的规章制度应组织培训；**安全操作规程类**还应组织相关人员**考试** |
| **7. 反馈** | 定期检查执行中存在的问题，或建立信息反馈渠道，及时掌握执行效果 |
| **8. 持续改进** | 每年制定规章制度制定、修订计划，公布现行有效清单。**安全操作规程类**除每年审查修订外，**每 3-5 年应进行一次全面修订**并重新发布 |

<Callout type="tip">

**签发权限的记忆规律（高频）：**

- **技术性强的**（技术规程、安全操作规程）→ **主管生产的领导 或 总工程师**
- **全局性的综合管理制度** → **主要负责人**

**审核的三条线：** 法律事务部门（合规性）→ 专家（专业技术）→ 职代会（全员性规章）

**数字必背：安全操作规程类每 3-5 年全面修订一次**

</Callout>

<h3>1.4 安全操作规程的内容与编写</h3>

**（1）安全操作规程的内容（10 项）：**
①操作前的准备 ②劳动防护用品的穿戴要求 ③操作的先后顺序、方式 ④操作过程中机器设备的状态 ⑤操作过程中需要进行哪些测试和调整，如何进行 ⑥操作人员所处的位置和操作时的规范姿势 ⑦操作过程中有哪些必须禁止的行为 ⑧一些特殊要求 ⑨异常情况如何处理 ⑩其他要求

**（2）安全操作规程的编写：**

| 要点 | 内容 |
|---|---|
| **格式分类** | 分**全式**和**简式**。**全式**由总则或适用范围、引用标准、名词说明、操作安全要求构成；**简式**一般由操作安全要求构成。**企业内部**制定通常采用**简式**，文字应简明 |
| **简单明了** | 可将安全操作规程**图表化、流程化**，一目了然，便于应用 |
| **严格执行** | 编写完成后应**广泛征求设备管理部门和使用部门意见**，进一步修改完善，经过审批，作为企业内部标准**严格执行** |
| **及时修订** | 随生产工艺变化、新设备使用、新材料和新技术应用，操作方式方法会变化，应及时修订 |

**记忆锚点：再培训强调一个「新」字。**

</Callout>

<h3>2.2 特种作业人员培训</h3>

**（1）特种作业目录（应急管理类 11 个类别、62 个项目）：**

| 序号 | 类别 | 具体作业 |
|---|---|---|
| 1 | 电工作业 | 高压电工、低压电工、电力电缆、继电保护、电气试验 |
| 2 | 焊接与热切割作业 | 熔化焊接与热切割作业 |
| 3 | 高处作业 | 登高架设作业；高处安装、维护、拆除作业 |
| 4 | 涉氨制冷作业 | 涉氨制冷设备运行、维修操作作业 |
| 5 | 煤矿安全作业 | 煤矿井下电气作业、煤矿井下爆破作业、煤矿调度作业等 **14 个**类别 |
| 6 | 金属非金属矿山安全作业 | 金属非金属矿井通风作业、尾矿作业等 **7 个**类别 |
| 7 | 石油天然气安全作业 | 陆上石油钻井司钻作业、陆上石油井下作业司钻作业等 **6 个**作业 |
| 8 | 冶金、有色、建材生产安全作业 | 煤气作业 |
| 9 | 危险化学品安全作业 | 光气及光气化工艺作业、氯碱电解工艺作业等 **19 个**类别 |
| 10 | 烟花爆竹安全作业 | 烟火药及效果件制造作业、黑火药制造作业等 **5 个**类别 |
| 11 | 有限空间安全作业 | 有限空间监护作业 |

**（2）特种作业人员的条件：**
- ①年满 **18 周岁**，且**不超过国家法定退休年龄**
- ②**无**器质性心脏病、癫痫病、美尼尔氏症、眩晕症、癔症、帕金森病、精神病、痴呆以及影响肢体活动的神经系统疾病，且无妨碍安全作业的身体缺陷
- ③具备必要的安全技术知识与技能
- ④相应特种作业规定的其他条件
- **危险化学品特种作业人员、首次取证的地下矿山特种作业人员**应当具备**高中或相当于高中及以上文化程度**

**（3）培训与免培训：**

| 项目 | 要求 |
|---|---|
| **安全技术培训** | ①包括**理论培训和实际操作培训**<br/>②应当以**单位自主培训**为主，也可委托具备条件的机构或通过应急管理部规定的其他方式<br/>③委托其他机构培训的，**保证安全技术培训的责任仍由本单位负责** |
| **免培训**（两种情形） | ①已取得**中等职业学校（含技工学校）及以上学历**的毕业生，申请与**所学专业相应**的特种作业操作证，持学历证明经考核发证机关同意，可免予安全技术培训<br/>②持有**合法有效的职业技能等级证书**的从业人员，申请与其**职业技能相应**的特种作业操作证，可免予安全技术培训 |

**（4）考核发证：**

| 环节 | 要求 |
|---|---|
| **考核** | ①包括**安全技术考试和资格审核**。安全技术考试由考核发证机关负责（可委托考试机构实施）；资格审核由考核发证机关负责<br/>②执行**全国统一**的考核标准，使用**全国统一**的考试题库和考试系统<br/>③包括**理论考试和实际操作考试**两部分，**均合格**才视为安全技术考试合格<br/>④**理论考试合格后**方可参加实际操作考试；实际操作考试**不得超过 5 次**，仍不合格的应**重新参加理论考试**<br/>⑤每次不合格可按规定**免费补考**<br/>⑥申请人应自考试申请通过之日起 **3 年内**完成安全技术考试 |
| **发证** | ①考核发证机关或其委托的考试机构在考试结束后 **10 个工作日内**公布成绩<br/>②考试合格者由本人或委托他人向**考试所在地**的考核发证机关申领，考核发证机关自受理之日起 **20 个工作日内**审查；符合条件的颁发证书并上传至全国统一证书查询平台<br/>③特种作业操作证**有效期为 6 年**，**全国范围内有效** |
| **换证** | ①有效期届满需继续从事的，应**换领新证**<br/>②应在有效期届满前 **6 个月内**完成相应的**理论培训和理论考试**，并在届满前 **60 日内**提出换证申请 |
| **失效** | ①未按规定换证或延期换证的，有效期届满时**失效**<br/>②失效未超过 **1 年**的，按**换证**办理；失效超过 **1 年**的，按**首次取证**办理。证书失效期间**不得**从事特种作业<br/>③因服兵役、出国（境）工作学习等特殊原因无法按期换证的，**延期时间最长不得超过 2 年**，延期期间不得从事特种作业 |

<Callout type="tip">

**特种作业数字速记：**

- 年龄：**18 周岁**起，不超法定退休年龄
- 实际操作考试：不超 **5 次**
- 完成考试：**3 年内**
- 公布成绩：**10 个工作日**
- 审查发证：**20 个工作日**
- 证书有效期：**6 年**
- 理论培训考试：届满前 **6 个月内**
- 提出换证申请：届满前 **60 日内**
- 失效 ≤ **1 年**按换证，＞**1 年**按首次取证
- 延期最长：**2 年**

</Callout>

<h3>2.3 其他从业人员的教育培训</h3>

**（1）三级安全教育培训：**

| 级别 | 培训重点 |
|---|---|
| **厂级** | 生产经营单位**安全风险辨识、安全生产管理目标、规章制度、劳动纪律、安全考核奖惩、从业人员的安全生产权利和义务**、有关事故案例等 |
| **车间级** | 本岗位工作及作业环境范围内的**安全风险辨识、评价和控制措施**，典型事故案例，岗位安全职责、操作技能及强制性标准，**自救互救、急救方法、疏散和现场紧急情况的处理**，安全设施、个人防护用品的使用和维护 |
| **班组级** | ①**岗位安全操作规程、岗位之间工作衔接配合、作业过程的安全风险分析方法和控制对策**、事故案例等<br/>②从业人员工作岗位确定后，由**班组**组织，班组长、班组技术员、安全员对其进行培训，除此之外**自我学习是重点**<br/>③我国传统的**师傅带徒弟**方式也是重要方法。新从业人员都应有具体的**跟班学习、实习期**，**实习期间不得安排单独上岗作业** |

<Callout type="tip">

**三级培训的「分工口诀」：**

- **厂级** → 管「**大方向**」（风险辨识、目标、制度、纪律、奖惩、权利义务）
- **车间级** → 管「**本岗位环境**」（风险辨识与控制、自救互救、急救、疏散、防护用品）
- **班组级** → 管「**具体操作**」（安全操作规程、岗位衔接、风险分析方法）

**实习期要求**：进入班组的新从业人员有跟班学习、实习期，**实习期间不得安排单独上岗作业**。

</Callout>

**（2）调整工作岗位或离岗后重新上岗：**
- 在本单位内**调整工作岗位**或**离岗一年以上**重新上岗时，应当重新接受**车间（工段、区、队）和班组级**的安全培训，**原则上由车间组织**
- 离开岗位时间自行确定，**风险大要求高的岗位时间间隔短**，电力行业规定 **3 个月**
- 采用**新工艺、新技术、新材料或使用新设备**时，应当对有关从业人员重新进行**有针对性的安全培训**

**（3）岗位安全教育培训：**
- **日常安全教育**：重点是安全操作规程、安全生产规章制度、作业岗位安全风险辨识、事故案例教育。实行**班前会、班后会制度、"安全日活动"制度**
- **定期安全考试**：定期学习规程、规章制度、事故案例，学习方式灵活但**考试统一组织**。不合格者应**下岗接受培训**，考试合格后方可上岗
- **专题安全教育培训**：针对某一具体问题的专门培训。通常包括"**三新**"安全教育培训、法律法规及规章制度培训、事故案例培训、安全知识竞赛、技术比武等

## 第三节 建设项目"三同时"管理

<h3 id="s3">3.1 "三同时"的监管责任</h3>

**（1）非煤矿山类项目**（需实施安全设施设计审查和竣工验收）：

| 项目类型 | 项目规模 |
|---|---|
| 海洋石油天然气 | **所有** |
| 企业投资陆上新油田 | 年产 **100 万吨**及以上 |
| 企业投资陆上新气田 | 年产 **20 亿立方米**及以上 |
| 金属非金属地下矿山 | 设计生产能力 **300 万吨/年**以上 或 设计最大开采深度 **1000 米**以上 |
| 金属非金属露天矿山 | 设计生产能力 **1000 万吨/年**以上 或 设计边坡 **200 米**以上 |
| 尾矿库 | 设计总库容 **1 亿立方米** 或 设计总坝高 **200 米**以上 |

**（2）危险化学品类建设项目：**

**应急管理部**负责实施下列建设项目的安全审查（安全条件审查、安全设施的设计审查）：
- ①**国务院**审批（核准、备案）的
- ②**跨省、自治区、直辖市**的

**省级应急管理部门**负责安全审查：
- ①**国务院投资主管部门**审批（核准、备案）的
- ②生产**剧毒化学品**的
- ③省级确定的除国务院审批（核准、备案）以外的其他建设项目

<Callout type="info">

**委托实施安全审查的规定（易考）：**

- 负责实施安全审查的部门**可以委托下一级**实施，**审查结果由委托的部门负责**
- **不得委托**的情形：**跨省、自治区、直辖市**的建设项目 和 **生产剧毒化学品**的建设项目
- **不得委托县级**实施的情形：①涉及应急管理部公布的**重点监管危险化工工艺**的；②涉及重点监管危险化学品中的**有毒气体、液化气体、易燃液体、爆炸品，且构成重大危险源**的
- 接受委托的部门**不得再委托**其他单位实施

</Callout>

**（3）其他行业建设项目：**
- 县级以上地方各级应急管理部门对本行政区域内建设项目安全设施"三同时"实施**综合监督管理**
- **跨两个及两个以上行政区域**的建设项目，由其**共同的上一级**人民政府安全生产监督管理部门实施监督管理
- 上一级部门**可以委托下一级**实施监督管理

<h3>3.2 "三同时"的设计审查</h3>

**（1）需向应急管理部门提出审查申请的 4 类项目：**
①非煤矿矿山建设项目 ②生产、储存危险化学品（包括使用长输管道输送）的建设项目 ③生产、储存烟花爆竹的建设项目 ④金属冶炼建设项目

**其他建设项目**安全设施设计，由生产经营单位**组织审查**，形成**书面报告备查**。

**（2）设计审查需提交的资料：**
①建设项目审批、核准或备案的文件 ②建设项目安全设施设计审查申请 ③设计单位的**设计资质证明文件** ④建设项目安全设施设计 ⑤建设项目**安全预评价报告**及相关文件资料 ⑥法律、行政法规、规章规定的其他文件资料

**（3）设计有下列情形之一的，不予批准，并不得开工建设（6 种）：**
①无建设项目审批、核准或备案文件的
②未委托**具有相应资质**的设计单位进行设计的
③安全预评价报告由**未取得相应资质**的安全评价机构编制的
④设计内容**不符合**有关安全生产的法律、法规、规章和国家标准或行业标准、技术规范的规定的
⑤**未采纳**安全预评价报告中的安全对策和建议，且**未作充分论证说明**的
⑥不符合法律、行政法规规定的其他条件的

**（4）已批准的项目，有下列情形之一的，应报原批准部门审查同意，未经同意不得开工（3 种）：**
①建设项目的**规模、生产工艺、原料、设备发生重大变更**的
②**改变安全设施设计**且可能**降低安全性能**的
③在**施工期间重新设计**的

<h3>3.3 "三同时"的施工、试运行、竣工验收</h3>

**（1）施工：**
- 安全设施施工应由**取得相应资质**的施工单位进行，并与**主体工程同时施工**
- 施工单位应在施工组织设计中编制**安全技术措施和施工现场临时用电方案**，同时对**危险性较大的分部分项工程**依法编制**专项施工方案**并附具**安全验算结果**，经**施工单位技术负责人、总监理工程师签字**后实施
- 施工单位**发现安全设施设计文件有错漏**的，应及时向生产经营单位、设计单位提出
- 施工单位**发现重大事故隐患**时，应**立即停止施工**并报告生产经营单位整改，**整改合格后方可恢复施工**
- **工程监理单位**应审查施工组织设计中的安全技术措施或专项施工方案是否符合**工程建设强制性标准**；发现事故隐患应要求整改，**情况严重**的应要求**暂时停止施工**并及时报告；施工单位**拒不整改或不停工**的，应及时向**有关主管部门**报告

**（2）试运行：**

适用于：①非煤矿山建设项目 ②生产、储存危险化学品的建设项目 ③生产、储存烟花爆竹的建设项目 ④金属冶炼建设项目 ⑤使用危险化学品从事生产并且使用量达到规定数量的化工建设项目（属于危险化学品生产的除外）等。

<KeyPoint examWeight={3}>
**试运行关键数字：**

- 试运行时间应当**不少于 30 日，最长不得超过 180 日**（国家有关部门有规定或特殊要求的行业除外）
- **生产、储存危险化学品的建设项目和化工建设项目**，应当在**试运行前**将**试运行方案报负责建设项目安全许可的安全生产监督管理部门备案**

</KeyPoint>

**（3）竣工验收：**
- 建设项目安全设施**竣工或试运行完成后**，生产经营单位应当**委托具有相应资质的安全评价机构**对安全设施进行**验收评价**，并编制**建设项目安全验收评价报告**
- 建设项目竣工投入生产或使用前，生产经营单位应当**组织对安全设施进行竣工验收**，并形成**书面报告备查**
- **安全设施竣工验收合格后，方可投入生产和使用**

## 第四节 重大危险源管理

<h3 id="s4">4.1 重大危险源的安全包保责任制</h3>

**（1）主要负责人包保事项（8 项）：**
①组织建立重大危险源**安全包保责任制**并**指定技术负责人、操作负责人**
②组织制定重大危险源**安全生产规章制度和操作规程**，并确保有效执行
③组织对重大危险源的**管理和操作岗位人员**进行**安全技能培训**
④保证重大危险源安全生产所必需的**安全投入**
⑤督促、检查重大危险源安全生产工作
⑥组织制定并实施重大危险源**生产安全事故应急预案**
⑦组织在**危险化学品登记综合服务系统**中填报重大危险源信息，确保安全监测监控数据接入**危险化学品重大危险源安全风险监测预警系统**
⑧**每半年至少 1 次**组织重大危险源安全风险隐患排查

**（2）技术负责人包保事项：**
①按照《危险化学品重大危险源安全监控技术规范》（**GB 17681**）组织建设重大危险源**安全监控系统**
②定期组织对安全设施和重大危险源安全监控系统进行**检测、检验、维护、保养**
③组织确认涉及重大危险源的**生产装置和储存设施的外部安全防护距离**是否符合标准规范要求
④组织审查涉及重大危险源作业的**承包商相关资质**、安全管理情况以及作业人员资格等，审查涉及重大危险源的**变更管理**
⑤**每季度至少组织一次**重大危险源安全风险隐患排查；**重大活动、重点时段和节假日前**均应组织排查
⑥组织重大危险源**专项应急预案和现场处置方案演练**

**（3）操作负责人包保事项（4 项）：**
①负责督促检查各岗位执行重大危险源安全生产规章制度和操作规程的情况
②对涉及重大危险源的**特殊作业、检维修作业**等进行监督检查
③**每周至少组织一次**重大危险源安全风险隐患排查
④及时采取措施消除重大危险源事故隐患

<Callout type="tip">

**三级包保的排查频次（必考数字）：**

| 角色 | 排查频次 |
|---|---|
| **主要负责人** | **每半年至少 1 次** |
| **技术负责人** | **每季度至少 1 次** |
| **操作负责人** | **每周至少 1 次** |

**记忆：主要半年 → 技术季度 → 操作每周**（层级越低，频次越高）

</Callout>

<h3>4.2 重大危险源的辨识与分级</h3>

**（1）评价单元的划分：**

| 类型 | 依据 | 标志 |
|---|---|---|
| **生产单元** | 危险化学品的生产、加工及使用等的装置及设施，当装置及设施之间有**切断阀**时，以切断阀作为分隔界限划分为独立的单元 | **切断阀** |
| **储存单元** | ①储罐区以罐区**防火堤**为界限<br/>②仓库以**独立库房（独立建筑物）** | **防火堤 / 独立房** |

<Callout type="info">

**两个特别注意：**
- **配管桥区** → **可作为**独立的评价单元
- **散设地上的管道** → **不可**作为独立的单元处理

</Callout>

**（2）重大危险源的判定：**

- **单一品种**：危险化学品的数量 **≥ 临界量**，则为重大危险源
- **多品种**：按下式计算，满足则定为重大危险源：

> **S = q₁/Q₁ + q₂/Q₂ + …… + qₙ/Qₙ ≥ 1**

其中 q 为每种危险化学品**实际存在量**（t，**按设计最大量确定**），Q 为与之对应的**临界量**（t）。

**（3）重大危险源的分级：**

**校正系数 β 的取值优先顺序**（同一危险化学品具有多种类别时）：

> **毒性气体 ＞ 爆炸品 ＞ 易燃气体 ＞ 其他危化品**

**校正系数 α 的取值**（根据厂区边界向外扩展 **500m** 范围内常住人口数量）：

| 常住人口 | α 值 |
|---|---|
| 0 人 | **0.5** |
| 1~29 人 | **1.0** |
| 30~49 人 | **1.2** |
| 50~99 人 | **1.5** |
| ≥100 人 | **2.0** |

**重大危险源分级标准：**

| 重大危险源等级 | R 值 | 对应事故等级 | 重伤人数（含急性工业中毒） |
|---|---|---|---|
| **一级** | ≥100 | 特别重大事故 | ≥100 人 |
| **二级** | 50（含）~100 | 重大事故 | 50（含）~100 人 |
| **三级** | 10（含）~50 | 较大事故 | 10（含）~50 人 |
| **四级** | ＜10 | 一般事故 | ＜10 人 |

<Callout type="tip">

**分级口诀：R 值与事故等级对应**

- 一级 ↔ 特别重大（≥100）
- 二级 ↔ 重大（50~100）
- 三级 ↔ 较大（10~50）
- 四级 ↔ 一般（＜10）

**α 值速记：0人=0.5，1-29=1.0，30-49=1.2，50-99=1.5，≥100=2.0**
（人数越多，α 越大，说明风险越高）

</Callout>

## 第五节 特种设备安全管理

<h3 id="s5">5.1 特种设备的分类</h3>

**承压类：**

| 类别 | 划分标准 |
|---|---|
| **锅炉** | **承压蒸汽锅炉**：容积 **≥30L**，且压力 **≥0.1MPa**<br/>**承压热水锅炉**：出口水压 **≥0.1MPa**（表压），且额定功率 **≥0.1MW**<br/>**有机热载体锅炉**：功率 **≥0.1MW** |
| **压力容器** | **固定式与移动式容器**：①最高工作压力 **≥0.1MPa**（表压）②容积 **≥30L** 且内直径 **≥150mm** ③介质为气体、液化气体和最高工作温度 ≥标准沸点的液体<br/>**气瓶**：①公称工作压力 **≥0.2MPa**（表压）②压力与容积的乘积 **≥1.0MPa·L** ③盛装介质为气体、液化气体和标准沸点 **≤60℃** 液体<br/>**氧舱**：只要是氧舱就是特种设备 |
| **压力管道** | ①压力 **≥0.1MPa** ②介质为气体、液化气体、蒸汽或者可燃、易爆、有毒、有腐蚀性、最高工作温度 ≥标准沸点的液体 ③公称直径 **≥50mm** |

<Callout type="info">
**压力管道的例外**：公称直径小于 **150mm** 且最高工作压力小于 **1.6MPa**，输送**无毒、不可燃、无腐蚀性气体**的管道和设备本体所属管道**除外**。
</Callout>

**机电类：**

| 类别 | 划分标准 |
|---|---|
| **电梯** | 载人（货）电梯、自动扶梯、自动人行道 |
| **起重机械** | **升降机**：额定起重量 **≥0.5t**<br/>**起重机**：①提升高度 **≥2m** ②额定起重量 **≥3t**（塔式起重机额定起重力矩 **≥40t·m**，装卸桥生产率 **≥300t/h**）<br/>**机械式停车设备**：层数 **≥2 层** |
| **客运索道** | 客运架空索道、客运缆车、客运拖牵索道等<br/>**例外**：非公用客运索道和专用于单位内部通勤的客运索道除外 |
| **大型游乐设施** | ①最大运行线速度 **≥2m/s** ②或运行高度 **≥2m**<br/>**例外**：用于体育运动、文艺演出和非经营活动的大型游乐设施除外 |
| **场（厂）内专用机动车辆** | **机动工业车辆（叉车）**：平衡重式、前移式、侧面式、插腿式叉车、托盘堆垛车、三向堆垛式叉车<br/>**非公路用旅游观光车辆**：观光车和观光列车 |

<Callout type="tip">
**关键数字速记：**

- 锅炉：容积 **≥30L** 且压力 **≥0.1MPa**；有机热载体 **≥0.1MW**
- 气瓶：压力 **≥0.2MPa**，压力×容积 **≥1.0MPa·L**，沸点 **≤60℃**
- 压力管道：公称直径 **≥50mm**，压力 **≥0.1MPa**
- 升降机 **≥0.5t**；起重机提升高度 **≥2m**、额定起重量 **≥3t**
- 机械式停车设备 **≥2 层**
- 大型游乐设施 **≥2m/s** 或 **≥2m**

**记忆锚点**：容器类都是「**30L / 0.1MPa**」，气瓶升级到「**0.2MPa / 1.0MPa·L**」。
</Callout>

<h3>5.2 特种设备的使用登记</h3>

- 特种设备在**投入使用前**或**投入使用后 30 日内**，使用单位应当向**直辖市或者设区的市**的特种设备安全监督管理部门**登记**
- 办理使用登记的部门**可以委托其下一级**办理
- 对于**整机出厂**的特种设备，一般应当在**投入使用前**办理使用登记
- **登记标志**应当置于或附着于该特种设备的**显著位置**

**特殊情形：**

| 设备 | 登记机关 |
|---|---|
| 移动式压力容器、车用气瓶、流动式起重机、场（厂）内专用机动车辆 | 应当在**投入使用前**，向**产权单位所在地**的登记机关申请<br/>流动式起重机和场（厂）内专用机动车辆**出租使用**时，也可向**承租单位所在地**的登记机关申请 |
| 车用气瓶产权属于个人的 | 产权单位所在地是指**机动车注册登记地** |
| **D 级锅炉**等 | **不用办理**使用登记 |

**登记标准：**

| 标准 | 设备 |
|---|---|
| **按台（套）办理** | 锅炉、压力容器（气瓶除外）、电梯、起重机械、客运索道、大型游乐设施和场（厂）内专用机动车辆；**车用气瓶以车为单位** |
| **按单位办理** | **气瓶（车用气瓶除外）、工业管道**，以**使用单位**为对象 |

<h3>5.3 特种设备的安全技术档案</h3>

**速记：证、表、文件、方案 + 5 记录**

1. **使用登记证**
2. **《特种设备使用登记表》**
3. 设计、制造技术资料和文件（设计文件、**产品质量合格证明**、安装及使用维护保养说明、监检证书等）
4. 安装、改造和修理的**方案、图样、材料质量证明书和施工质量证明文件**、安装改造修理监督检验报告、验收报告等技术资料
5. 特种设备的**日常使用状况记录**
6. 特种设备及其附属仪器仪表的**维护保养记录**
7. 特种设备**安全附件和安全保护装置**校验、检修、更换记录和有关报告
8. 特种设备**运行故障和事故记录**及事故处理报告
9. **《特种设备安全风险管控清单》**及相关工作记录
10. 特种设备**定期检验报告、定期自行检查记录（报告）或自行检测报告**

<h3>5.4 安装、维护保养、改造和定期检验</h3>

- **锅炉、压力容器、起重机械、客运索道、大型游乐设施**的安装、改造、维修，以及**场（厂）内专用机动车辆**的改造、维修，必须由**依法取得许可**的单位进行
- **电梯**的安装、改造、维修，必须由**电梯制造单位**或**其通过合同委托、同意的依法取得许可的单位**进行。电梯制造单位对电梯质量以及安全运行涉及的质量问题负责
- 安装、改造、维修的施工单位应当在**施工前**将情况**书面告知**直辖市或者设区的市的特种设备安全监督管理部门，**告知后即可施工**
- 使用单位应当进行**经常性维护保养和定期自行检查**并作出记录；对**安全附件、安全保护装置**进行定期校验、检修并作出记录
- 使用单位应当按照安全技术规范要求，在**检验合格有效期届满前一个月**向特种设备检验机构提出**定期检验**要求，并将定期检验标志置于**显著位置**。**未经定期检验或检验不合格的，不得继续使用**
- **电梯**日常维护保养必须由取得许可的安装、改造、维修单位或电梯制造单位进行。电梯应当**至少每 15 日**进行一次清洁、润滑、调整和检查
- 使用单位对在用特种设备应当**至少每月进行一次自行检查**并作出记录
- **锅炉定期检验**包括外部检验、内部检验、水（耐）压试验。成套装置中的锅炉或 A 级高压以上电站锅炉因检修周期等原因不能按期进行内部检验时，在保证安全运行（或停运）的前提下，在**使用单位主要负责人审批后**，可以延期安排内部检验（**一般不超过一年并且不得连续延期**），并向**锅炉使用登记机关备案**

<Callout type="tip">
**三个频次/时限必背：**

- **电梯**清洁、润滑、调整和检查：至少每 **15 日**一次
- 在用特种设备**自行检查**：至少每 **1 个月**一次
- 申请**定期检验**：检验合格有效期届满前 **1 个月**

**记忆**：电梯 15 日（最勤）→ 自行检查 1 月 → 定期检验提前 1 月
</Callout>

<h3>5.5 特种设备的报废</h3>

- 对存在**严重事故隐患、无改造修理价值**，或达到安全技术规范规定的**报废条件**的，应当及时予以报废，使用单位应采取必要措施**消除该特种设备的使用功能**
- 报废时，按台（套）登记的应**办理报废手续**，填写**《特种设备停用报废注销登记表》**，向登记机关办理报废手续，并将**使用登记证交回**登记机关
- 对达到设计使用年限但**未达到报废条件**，使用单位希望继续使用的：
  - **需修理改造的**：由具有相应资格的单位修理改造后，经特种设备检验机构**监督检验合格**
  - **不需修理改造的**：由使用单位申请**安全评估**，经具有相应许可资格的制造单位或其他专业技术机构安全评估，作出**可以继续使用**的结论
- **责任转移**：对达到设计使用年限的特种设备，**原制造企业不再承担**相应安全责任，而是由对其进行**修理、改造或安全评估的机构**承担

## 第六节 安全技术措施与安全色标志

<h3 id="s6">6.1 安全技术措施的分类</h3>

按**导致事故的原因**，分两类：**防止事故发生的**安全技术措施 和 **减少事故损失的**安全技术措施。

**防止事故发生的安全技术措施：**

| 措施 | 内容与举例 |
|---|---|
| **消除危险源** | 从根本上防止事故发生。①选择合适的工艺、技术、设备和设施（如**防爆电气设备**的选择）②合理的结构形式（如设计合理的**安全距离**、避免锐边尖角）③选择无害、无毒或不能致人伤害的物料（如**无毒替换有毒**） |
| **限制能量或危险物质** | ①**减少**能量或危险物质的量（定量储存、电机设定安全转速、受限空间内设置 **12~36V** 的安全电压）②**防止能量积蓄**（爆炸气体浓度控制、机械通风）③**安全地释放能量**（设置压力容器的流量调节阀或压力调节阀） |
| **隔离** | 常用的控制能量或危险物质的安全技术措施。既可防止事故发生，也可防止事故扩大。例如：机械装置的**安全防护罩或安全防护壳**、室内外变压器的**安全栅栏** |
| **故障—安全设计** | 在系统、设备设施的一部分发生故障或破坏的情况下，在一定时间内也能保证安全的技术措施 |

<Callout type="tip">
**记忆线索：消除 → 限制 → 隔离 → 故障安全设计**

（从「根本消除」到「兜底防护」，防护层级由强到弱）

**易考点**：安全防护罩、安全栅栏属于「**隔离**」；防爆电气设备的选择属于「**消除危险源**」。
</Callout>

<h3>6.2 安全色与安全标志</h3>

- **安全色**：用于表达特定安全信息的颜色（红、蓝、黄、绿）
- **安全标志**：依据 **GB 2894** 设置
- 腐蚀性介质的作业场所应在现场就近（**30m 内**）配备人员应急用冲洗水源

<Callout type="tip">
**安全色含义（通用）**：**红**=禁止/停止、**黄**=警告、**蓝**=指令、**绿**=提示/安全状态
</Callout>

<h3>6.3 噪声管理与 5S 管理</h3>

- 噪声管理：控制作业场所噪声危害，采取隔声、吸声、消声等措施
- **5S 管理**：整理、整顿、清扫、清洁、素养

## 第七节 安全生产费用与责任保险

<h3 id="s7">7.1 安全生产费用的用途与管理</h3>

**企业安全生产费用属于企业自提自用资金**，除集团总部按规定统筹使用外，**任何单位和个人不得采取收取、代管等形式**对其进行集中管理和使用。

**管理要点：**

| 要点 | 内容 |
|---|---|
| 集团统筹 | 承担集团安全生产责任的企业集团母公司（**一级，即集团总部**）可以对全资及控股子公司提取的安全生产费用按一定比例**集中管理、统筹使用**。子公司转出资金作为安全生产费用支出处理，集团总部收到资金作为**专项储备**管理，**不计入集团总部收入** |
| 优先用途 | 在本办法规定的使用范围内，应当**优先用于达到法定安全生产标准所需支出**和按各级应急管理部门等要求开展的**安全生产整改支出** |
| 产权变更 | 由于**产权转让、公司制改建**等变更股权结构或组织形式的，其**结余**的安全生产费用应当**继续**按本办法管理使用 |
| 清算处理 | 企业调整业务、终止经营或依法清算的，结余应结转本期收益或清算收益。**两个例外**：①**矿山企业**转产、停产、停业或解散的，结余用于**矿山闭坑、尾矿库闭库**后可能的危害治理和损失赔偿；②**危险品生产与储存企业**的结余用于处理转产、停产、停业或解散前的**危险品生产或储存设备、库存产品及生产原料支出** |

<h3>7.2 安全生产责任保险（安责险）</h3>

| 项目 | 内容 |
|---|---|
| **行业范围** | 矿山、危险化学品、烟花爆竹、交通运输、建筑施工、民用爆炸物品、金属冶炼、渔业生产等**高危行业、领域**<br/>**助记口诀：金矿危烟，建交爆渔** |
| **赔偿范围** | ①被保险人因生产安全事故造成的依法应负的**从业人员人身伤亡赔偿**<br/>②**第三者**人身伤亡和财产损失赔偿<br/>③相关**事故抢险救援、医疗救护、事故鉴定、法律诉讼**等费用 |
| **缴纳责任** | 生产经营单位应当**及时足额缴纳**，**不得以任何方式摊派给从业人员个人**。保费可以据实从企业**安全生产费用中列支** |
| **责任限额** | 每人死亡伤残责任限额**不得低于 40 万元** |
| **覆盖范围** | 覆盖**全体从业人员**，保险金额实行**同一标准**，不得因**用工方式、工作岗位**等差别对待。临时聘用人员、被派遣劳动者等有用工关系的人员**纳入从业人员范畴** |

<Callout type="tip">
**安责险三要点：**

1. **八个高危行业**：口诀「**金矿危烟，建交爆渔**」（金属冶炼、矿山、危险化学品、烟花爆竹、建筑施工、交通运输、民用爆炸物品、渔业生产）
2. **不得摊派给个人**
3. **每人死亡伤残责任限额最低 40 万元**

**高频易错**：安责险覆盖**全体从业人员**，保险金额**同一标准**，不得因用工方式、岗位差别对待。
</Callout>

## 第八节 隐患排查治理与个体防护

<h3 id="s8">8.1 隐患排查治理</h3>

<KeyPoint examWeight={3}>
**核心定性：生产经营单位是事故隐患排查、治理和防控的责任主体。**
</KeyPoint>

**（1）发包出租情形：**
生产经营单位将项目、场所、设备**发包、出租**的，应当与承包、承租单位签订**安全生产管理协议**，明确各方对事故隐患排查、治理和防控的管理职责。生产经营单位对承包、承租单位的隐患排查治理负有**统一协调和监督管理**的职责。

**（2）统计分析报送：**
- 应当**每季、每年**对本单位事故隐患排查治理情况进行统计分析
- 分别于**下一季度 15 日前**和**下一年 1 月 31 日前**向安全监管监察部门和有关部门报送**书面统计分析表**
- 统计分析表应当由**主要负责人签字**

**（3）重大事故隐患报告内容（3 项）：**
①隐患的**现状及其产生原因**
②隐患的**危害程度和整改难易程度分析**
③隐患的**治理方案**

**（4）隐患整改责任划分：**

| 隐患类型 | 整改责任 |
|---|---|
| **一般事故隐患** | 由生产经营单位（**车间、分厂、区队等**）**负责人或有关人员立即组织整改** |
| **重大事故隐患** | 由生产经营单位**主要负责人**组织制定并实施**事故隐患治理方案** |

**重大事故隐患治理方案内容（6 项）：**
①治理的**目标和任务** ②采取的**方法和措施** ③**经费和物资**的落实 ④负责治理的**机构和人员** ⑤治理的**时限和要求** ⑥**安全措施和应急预案**

**（5）治理过程中的安全措施：**
事故隐患排除前或排除过程中**无法保证安全**的，应当：
- 从**危险区域内撤出作业人员**，并疏散可能危及的其他人员
- 设置**警戒标志**
- **暂时停产停业或停止使用**
- 对暂时难以停产或停止使用的相关生产储存装置、设施、设备，应当**加强维护和保养**

**（6）监管部门的处理：**
- 对检查发现的重大事故隐患，应当下达**整改指令书**，并建立**信息管理台账**
- 必要时，报告同级人民政府并对重大事故隐患实行**挂牌督办**
- 对**挂牌督办并采取全部或局部停产停业治理**的重大事故隐患，监管部门收到恢复生产申请报告后，应当在 **10 日内**进行**现场审查**。审查合格的对事故隐患进行**核销**，同意恢复生产；审查不合格的依法责令改正或下达停产整改指令

<Callout type="tip">
**隐患治理的数字速记：**

- 统计分析报送：下季度 **15 日前** / 次年 **1 月 31 日前**
- 恢复生产申请后现场审查：**10 日内**

**责任划分记忆：一般隐患 → 车间/分厂/区队负责人；重大隐患 → 主要负责人**
</Callout>

<h3>8.2 个体防护装备管理</h3>

- 用人单位应在**入库前**对个体防护装备进行**进货验收**，确定产品是否符合国家或行业标准；对国家规定应进行**定期强检**的个体防护装备，应委托**具有检测资质**的机构进行**定期检验**
- 应当安排**专项经费**用于配备个体防护装备，在成本中**据实列支**，**不得以货币或其他物品替代**
- 应对其使用的**劳务派遣工、临时聘用人员、接纳的实习生和允许进入作业地点的其他外来人员**进行个体防护装备的配备及管理

<KeyPoint examWeight={3}>
**配备流程的关键环节：危害因素的辨识和评估、个体防护装备的选择。**

**识别危害因素时应主要从 9 方面分析：**
①正常工作状态 ②异常工作状态 ③人员作业活动 ④设备采购、贮存和输送，以及设备设施的运行、维修和保养 ⑤原辅材料、中间产品和最终产品 ⑥生产、施工工艺 ⑦环境条件 ⑧管理制度 ⑨其他辅助活动和意外情况
</KeyPoint>

- 当有**新员工入职、员工转岗、个体防护装备配备发生变化、法律法规及标准发生变化**等情况，需要培训时应及时进行培训
- 个体防护装备应当妥善保存。**公用的防护装备应当由车间或班组统一保管**，定期维护

**判废与更换（4 种情形之一即应判废更换）：**
①经检验或检查被判定**不合格**
②**超过有效期**
③**功能已经失效**
④使用说明书中规定的其他判废或更换条件

<Callout type="tip">
**强制报废要求**：**安全帽、呼吸器、绝缘手套**等安全性能要求高、易损耗的个体防护装备，应当按照**有效防护功能最低指标和有效使用期，到期强制报废**。

**被判废或被更换后的个体防护装备不得再次使用。**

**高频易错**：个体防护装备**不得以货币或其他物品替代**（与劳动防护用品不能用金钱代替一致）。
</Callout>

## 第九节 八大特殊作业安全管理

<h3 id="s9">9.1 特殊作业通用管理要求</h3>

**（1）作业前危害辨识与交底：**
作业前应组织作业单位对作业现场和作业过程中可能存在的危险有害因素进行**辨识**，开展**作业危害分析**，制定相应的**安全风险管控措施**。

**安全措施交底主要包括：**
- a）作业现场和作业过程中可能存在的危险、有害因素及采取的具体安全措施与应急措施
- b）会同作业单位组织作业人员到**作业现场**，了解和熟悉现场环境，进一步核实安全措施的可靠性，熟悉**应急救援器材的位置及分布**
- c）涉及**断路、动土作业**时，应对作业现场的**地下隐蔽工程**进行交底

**（2）作业现场及设备检查要求：**
- a）作业现场**消防通道、行车通道**应保持畅通，影响作业安全的杂物应清理干净
- b）作业现场的**梯子、栏杆、平台、箅子板、盖板**等设施应完整、牢固
- c）可能危及安全的**坑、井、沟、孔洞**应采取有效防护措施并设**警示标志**；需要检修的**电器电源应可靠断电**，在电源开关处**加锁并加挂安全警示牌**
- d）作业使用的**个体防护器具、消防器材、通信设备、照明设备**等应完好
- e）**脚手架、起重机械、电气焊（割）用具、手持电动工具**等工器具符合作业安全要求；**超过安全电压**的手持式、移动式电动工器具应**逐个配置漏电保护器和电源开关**
- f）设置符合 **GB 2894** 的安全警示标志
- g）按照 **GB 30077** 要求配备应急设施
- h）**腐蚀性介质**的作业场所应在现场就近（**30m 内**）配备人员应急用冲洗水源

**（3）作业审批：**
- 作业前应组织办理**作业审批手续**，并由**相关责任人签字审批**
- **同一作业涉及两种或两种以上特殊作业**时，应**同时执行各自作业要求**，办理相应的作业审批手续
- **作业审批人应在作业现场完成审批工作**
- 作业内容**变更**、作业范围**扩大**、作业地点**转移**或超过**安全作业票有效期限**时，应**重新办理**安全作业票

<h3>9.2 特殊作业分级管理</h3>

<KeyPoint examWeight={3}>
**动火作业、高处作业、吊装作业实行分级管理，其余特殊作业不涉及分级。**
</KeyPoint>

**（1）动火作业分级：**

| 级别 | 划分标准 |
|---|---|
| **特级** | 在**火灾爆炸危险场所处于运行状态**下的生产装置设备、管道、储罐、容器等部位上进行的动火作业（包括**带压不置换动火作业**）；存有易燃易爆介质的**重大危险源罐区防火堤内**的动火作业 |
| **一级** | 在**火灾爆炸危险场所**进行的除特级动火作业以外的动火作业，**管廊上的动火作业按一级**管理 |
| **二级** | 除特级和一级以外的动火作业。生产装置或系统**全部停车**，装置经**清洗、置换、分析合格**并采取**安全隔离措施**后，根据其火灾、爆炸危险性大小，经企业**生产负责人或安全管理负责人批准**，可按二级动火作业管理 |

<Callout type="tip">
**动火作业关键规定：**

- 实行**一个动火点、一张动火证**的动火作业管理，**不得随意涂改和转让**动火证，**不得异地使用或扩大使用范围**
- 动火**开始时间是正式实际开始动火作业的时间**，**不包含作业准备时间**。作业期间可能存在的中断时间（如用餐时间等）**应计算在 8 小时之内**
- **遇节假日、公休日、夜间或其他特殊情况，动火作业应升级管理**

**注意**：动火作业有「升级管理」，**高处作业没有节假日、夜间升级管理**。
</Callout>

**（2）高处作业分级：**

| 分类法 | 2≤hw≤5 | 5＜hw≤15 | 15＜hw≤30 | hw＞30 |
|---|---|---|---|---|
| **A 类** | Ⅰ | Ⅱ | Ⅲ | Ⅳ |
| **B 类** | Ⅱ | Ⅲ | Ⅳ | Ⅳ |

**升级管理：存在以下一种或一种以上客观危险因素的，按 B 类法分级：**
①五级以上风力 ②Ⅱ级或Ⅱ级以上的高温作业 ③作业时间段平均气温等于或低于 5℃ ④接触冷水温度等于或低于 12℃ ⑤作业场地有冰、雪、霜、油、水等易滑物 ⑥作业场所光线不足或能见度差 ⑦作业活动范围与危险电压带电体距离小于规定 ⑧摆动或立足处不是平面或只有很小平面（**任一边小于 500mm** 的矩形平面、**直径小于 500mm** 的圆形平面）⑨Ⅲ级或Ⅲ级以上的体力劳动强度 ⑩空气中含氧量**低于 19.5%** 或存在有毒气体的作业环境

**（3）吊装作业分级：**

| 级别 | 质量标准 |
|---|---|
| **一级** | m ＞ 100t |
| **二级** | 40t ≤ m ≤ 100t |
| **三级** | m ＜ 40t |

**注意：吊装作业无升级管理。**

<h3>9.3 动火作业安全管理</h3>

**（1）作业基本要求：**

- 动火作业应有**专人监护**，作业前应清除动火现场及周围的**易燃物品**，或采取其他有效安全防火措施，并**配备消防器材**
- 凡在盛有或盛装过助燃或易燃易爆危险化学品的设备、管道等生产、储存设施及火灾爆炸危险场所中生产设备上的动火作业，应将上述设备设施与生产系统**彻底断开或隔离**，**不应以水封或仅关闭阀门代替盲板**作为隔断措施
- 动火点周围或其下方如有可燃物、电缆桥架、孔洞、窨井、地沟、水封设施、污水井等，应检查分析并采取清理或封盖等措施；对于动火点周围 **15m 范围内**有可能泄漏易燃、可燃物料的设备设施，应采取**隔离措施**
- 在有可燃物构件和使用可燃物做防腐内衬的设备内部进行动火作业时，应采取**防火隔绝措施**
- 在可能释放出易燃易爆、有毒有害物质的设备上或内部动火时，动火前应进行**风险分析**，必要时**连续检测气体浓度**，发现超限报警应立即停止作业；在较长的物料管线上动火，动火前应在**彻底隔绝区域内分段采样分析**
- 在**生产、使用、储存氧气**的设备上进行动火作业时，设备内**氧含量不应超过 23.5%**（体积分数）
- 在**油气罐区防火堤内**进行动火作业时，**不应同时进行切水、取样作业**

<KeyPoint examWeight={3}>
**动火作业距离与数字（高频必考）：**

- **动火期间，距动火点 30m 内**不应排放**可燃气体**
- **距动火点 15m 内**不应排放**可燃液体**
- 在**动火点 10m 范围内、动火点上方及下方**不应同时进行可燃溶剂清洗或喷漆作业
- 在**动火点 10m 范围内**不应进行**可燃性粉尘清扫**作业
- 在**厂内铁路沿线 25m 以内**动火作业时，如遇装有危险化学品的火车通过或停留，应立即停止作业
- **特级动火作业**应采集**全过程作业影像**，且摄录设备应为**防爆型**
- **使用电焊机**时，电焊机与动火点的间距**不应超过 10m**；不能满足时**应将电焊机作为动火点进行管理**
- **使用气焊、气割**时，**乙炔瓶应直立放置，不应卧放**；**氧气瓶与乙炔瓶间距不应小于 5m**，**二者与动火点间距不应小于 10m**，并应防晒防倾倒；**乙炔瓶应安装防回火装置**
- **遇五级风以上（含五级风）天气，禁止露天动火作业**；因生产确需动火的，**应升级管理**

</KeyPoint>

**（2）动火分析及合格判定指标：**

- 气体分析的**检测点要有代表性**，在较大的设备内动火，应对**上、中、下（左、中、右）**各部位进行检测分析
- 在**管道、储罐、塔器等设备外壁上**动火，应在动火点 **10m 范围内**进行气体分析，同时还应检测**设备内**气体含量
- **气体分析取样时间与动火作业开始时间间隔不应超过 30min**
- **特级、一级动火作业中断时间超过 30min**，**二级动火作业中断时间超过 60min**，应**重新**进行气体分析；**每日动火前均应进行气体分析**；**特级动火作业期间应连续进行监测**

**（3）固定动火区管理：**
固定动火区的设定应由企业**审批后确定**，设置**明显标志**；应**每年至少**对固定动火区进行一次**风险辨识**，周围环境发生变化时应及时辨识、重新划定。

<Callout type="tip">
**固定动火区 = 每天都可以动火的地方，不需要办理动火作业票**
</Callout>

<h3>9.4 受限空间作业安全管理</h3>

**（1）作业前安全隔离：**
- a）与受限空间连通的可能危及安全作业的**管道**应采用**加盲板或拆除一段管道**的方式进行隔离；**不应采用水封或关闭阀门代替盲板**
- b）与受限空间连通的**孔、洞**应进行**严密封堵**
- c）对作业设备上的**电器电源**，应采取**可靠的断电措施**，电源开关处应**上锁并加挂警示牌**

**（2）气体环境要求：**

<KeyPoint examWeight={3}>
- 作业前 **30 min 内**，对受限空间进行气体检测，**检测分析合格后方可进入**
- 检测点应有代表性，容积较大的受限空间，应对**上、中、下（左、中、右）**各部位进行检测分析
- 检测人员进入或探入受限空间检测时，应**佩戴规定的个体防护装备**
- **涂刷具有挥发性溶剂的涂料**时，应采取**强制通风措施**
- **不应向受限空间充纯氧气或富氧空气**
- 作业**中断时间超过 60min** 时，应**重新进行气体检测分析**
- **受限空间内气体检测：氧气含量为 19.5%~21%**（体积分数），在**富氧环境下不应大于 23.5%**（体积分数）
- 作业时现场应配置**移动式气体检测报警仪**，连续检测可燃气体、有毒气体及氧气浓度，并 **2h 记录 1 次**；气体浓度超限报警时应立即停止作业、撤离人员
</KeyPoint>

**（3）进入受限空间的防护措施（按环境类型）：**

| 环境 | 防护措施 |
|---|---|
| **缺氧或有毒** | 经清洗或置换仍达不到要求的，应佩戴满足要求的**隔绝式呼吸防护装备**，并正确**拴带救生绳** |
| **易燃易爆** | 应穿**防静电工作服及工作鞋**，使用**防爆工器具** |
| **存在酸碱等腐蚀性介质** | 应穿戴**防酸碱**防护服、防护鞋、防护手套等防腐蚀装备 |
| **从事电焊作业** | 应穿**绝缘鞋** |
| **有噪声** | 应佩戴**耳塞或耳罩**等防噪声护具 |
| **有粉尘** | 按要求佩戴**防尘口罩**等防尘护具 |
| **高温** | 应穿戴**高温防护用品**，必要时采取通风、隔热等措施 |
| **低温** | 应穿戴**低温防护用品**，必要时采取供暖措施 |
| **从事清污作业** | 应佩戴**隔绝式呼吸防护装备**，并正确**带救生绳** |
| 一般作业 | 应配备相应的**通信工具** |

**（4）监护人特殊要求：**
- a）**监护人应在受限空间外进行全程监护**，**不应在无任何防护措施的情况下探入或进入**受限空间
- b）在**风险较大**的受限空间作业时，应**增设监护人员**，并随时与内部作业人员保持联络
- c）监护人应对进入受限空间的人员及其携带的**工器具种类、数量进行登记**，作业完毕后再**再次清点**，防止遗漏

<h3>9.5 盲板抽堵作业安全管理</h3>

- **作业前应预先绘制盲板位置图**，对盲板进行**统一编号**，并设**专人统一指挥**
- 在不同企业**共用的管道**上进行盲板抽堵作业，作业前应**告知上下游相关单位**
- 应根据管道内介质的**性质、温度、压力和管道法兰密封面的口径**等选择相应材料、强度、口径和符合设计、制造要求的盲板及垫片，**高压盲板使用前应经超声波探伤**
- 作业单位应按**位置图**进行作业，并对每个盲板进行**标识**，标牌编号应与盲板位置图上的编号**一致**
- **作业前应降低系统管道压力至常压**，保持现场通风良好，并设**专人监护**
- 在**火灾爆炸危险场所**进行盲板抽堵作业时，作业人员应穿**防静电工作服、工作鞋**，并使用**防爆工具**；**距盲板抽堵作业地点 30m 内不应有动火作业**
- 在**强腐蚀性介质**的管道、设备上进行作业时，应采取**防止酸碱化学灼伤**的措施
- 在涉及**硫化氢、氯气、氨气、一氧化碳及氰化物**等毒性气体的管道、设备上进行作业时，除满足要求外，还应佩戴**移动式气体检测仪**
- **不应在同一管道上同时进行两处或两处以上的盲板抽堵作业**
- **同一盲板的抽、堵作业，应分别办理盲板抽堵安全作业票，一张安全作业票只能进行一块盲板的一项作业**
- 盲板抽堵作业结束，由**作业单位和危险化学品企业专人共同确认**

<Callout type="tip">
**盲板作业三个「一」：**

- **一张作业票 → 只能进行一块盲板的一项作业**（抽、堵要分别办票）
- **专人统一指挥** + 统一编号 + 位置图
- **30m 内不应有动火作业**
</Callout>

<h3>9.6 高处作业安全管理</h3>

- 高处作业人员应正确佩戴符合要求的**安全带及安全绳**，**30m 以上**高处作业应配备**通信联络工具**
- 高处作业应设**专人监护**，作业人员**不应在作业处休息**
- 作业人员**不应站在不牢固的结构物**上进行作业；在**彩钢板屋顶、石棉瓦、瓦楞板**等轻型材料上作业，应铺设牢固的**脚手板并加以固定**，脚手板上要有**防滑措施**
- 在邻近排放有毒、有害气体、粉尘的放空管线或烟囱等场所作业时，应预先与作业属地生产人员取得联系，作业人员应配备必要的防护装备（如**隔绝式呼吸防护装备、过滤式防毒面具或口罩**等）
- **雨天和雪天**作业时应采取可靠的**防滑、防寒**措施；**遇有五级风以上（含五级风）、浓雾等恶劣天气，不应进行高处作业、露天攀登与悬空高处作业**；暴风雪、台风、暴雨后应对作业安全设施进行检查
- 作业使用的工具、材料、零件应装入**工具袋**，上下时**手中不应持物**，**不应投掷**工具、材料及其他物品
- **在同一坠落方向上，一般不应进行上下交叉作业**；如需交叉作业，中间应设置**安全防护层**，坠落高度**超过 24m** 的交叉作业应设**双层防护**
- 拆除脚手架、防护棚时，应设**警戒区**并派专人监护，**不应上下同时施工**
- **安全作业票的有效期最长为 7 天**。当作业中断，再次作业前，应重新对环境条件和安全措施进行确认

<Callout type="tip">
**高处作业关键数字：**

- **30m 以上**配备通信联络工具
- 交叉作业坠落高度**超过 24m** 设**双层防护**
- 安全作业票有效期**最长 7 天**
- **五级风以上（含五级风）**不应进行高处作业
</Callout>

<h3>9.7 吊装作业安全管理</h3>

- **一、二级吊装作业应编制吊装作业方案**。吊装物体质量虽不足 40t，但**形状复杂、刚度小、长径比大、精密贵重**，以及在作业条件特殊的情况下，**三级吊装作业也应编制方案**；方案应经**审批**
- **大雪、暴雨、大雾、六级及以上大风**时，**不应露天作业**
- 应按规定负荷进行吊装，**不应超负荷吊装**
- **不应利用管道、管架、电杆、机电设备等作吊装锚点**；未经**土建专业人员审查核算**，不应将建筑物、构筑物作为锚点
- **起吊前应进行试吊**，试吊中检查全部机具、锚点受力情况，发现问题应立即将吊物放回地面

**吊装作业人员应遵守：**
- a）按指挥人员发出的**指挥信号**进行操作；**任何人发出的紧急停车信号均应立即执行**
- c）利用**两台或多台**起重机械吊运同一吊物时应保持同步，各台起重机械所承受的载荷**不应超过各自额定起重能力的 80%**
- d）下放吊物时，**不应自由下落（溜）**；**不应利用极限位置限制器停车**
- f）停工和休息时，**不应将吊物、吊笼、吊具和吊索悬在空中**
- g）**以下情况不应起吊**：①无法看清场地、吊物，指挥信号不明 ②起重臂吊钩或吊物下面有人、吊物上有人或浮置物 ③重物捆绑、紧固、吊挂不牢，吊挂不平衡，绳打结、绳不齐，斜拉重物，棱角吊物与钢丝绳之间没有衬垫 ④重物质量不明，与其他重物相连，埋在地下，与其他物体冻结在一起

**司索人员应遵守：**
- 听从指挥人员的指令，并及时报告险情
- **不应用吊钩直接缠绕吊物**及将不同种类或不同规格的索具混在一起使用
- 吊物捆绑应牢靠，吊点设置应根据吊物**重心位置**确定；吊运零散件时应使用专门的**吊篮、吊斗**等器具，吊篮、吊斗**不应装满**
- 吊物就位时应与吊物保持一定的安全距离，用**拉绳或撑杆、钩子**辅助其就位
- 吊物就位前，**不应解开吊装索具**

**监护人员应确保吊装过程中警戒范围区内没有非作业人员或车辆经过**；吊装过程中吊物及起重臂移动区域下方**不应有任何人员经过或停留**。

<Callout type="tip">
**风力等级的区分（高频易混）：**

| 作业类型 | 禁止作业的风力 |
|---|---|
| **动火作业** | **五级风以上**（含五级）禁止露天动火，需动火则升级管理 |
| **高处作业** | **五级风以上**（含五级）不应进行 |
| **吊装作业** | **六级及以上**大风不应露天作业 |

**记忆：动火、高处都是「五级」；吊装是「六级」**（吊装更危险，门槛更高）

**双机抬吊**：各台载荷**不超过各自额定起重能力的 80%**。
</Callout>

<h3>9.8 临时用电安全管理</h3>

- 在**运行的火灾爆炸危险性生产装置、罐区和具有火灾爆炸危险场所**内**不应接临时电源**，确需时应对周围环境进行**可燃气体检测分析**
- 各类**移动电源及外部自备电源，不应接入电网**
- 在开关上**接引、拆除临时用电线路**时，其**上级开关应断电、加锁，并挂安全警示标牌**，接、拆线路作业时应有**监护人在场**
- 临时用电应设置**保护开关**，使用前应检查电气装置和保护设施的可靠性。**所有的临时用电均应设置接地保护**
- 临时用电设备和线路应按**供电电压等级和容量**正确配置使用，电器元件应符合国家相关产品标准及作业现场环境要求，并有**良好的接地**

**临时用电还应满足：**
- a）火灾爆炸危险场所应使用**相应防爆等级**的电气元件，并采取相应的防爆安全措施
- b）临时用电线路及设备应有良好的**绝缘**，所有的临时用电线路应采用**耐压等级不低于 500V** 的绝缘导线
- c）临时用电线路经过**火灾爆炸危险场所以及有高温、振动、腐蚀、积水及产生机械损伤**等区域，**不应有接头**，并应采取相应的保护措施
- d）临时用电**架空线**应采用**绝缘铜芯线**，并应架设在**专用电杆或支架**上，其最大弧垂与地面距离，在**作业现场不低于 2.5m**，**穿越机动车道不低于 5m**
- f）对需**埋地敷设**的电缆线路应设有**走向标志和安全标志**。电缆埋地深度**不应小于 0.7m**，穿越道路时应加设**防护套管**
- g）现场临时用电**配电盘、箱**应有电压标志和危险标志，应有**防雨措施**，盘、箱、门应能**牢靠关闭并上锁管理**
- h）临时用电设施应安装符合规范要求的**漏电保护器**，移动工具、手持式电动工具应**逐个配置漏电保护器和电源开关**
- **未经批准**，临时用电单位**不应向其他单位转供电**或增加用电负荷，以及变更用电地点和用途

<KeyPoint examWeight={3}>
**临时用电关键数字：**

- 绝缘导线耐压等级**不低于 500V**
- 架空线最大弧垂离地：作业现场**不低于 2.5m**，穿越机动车道**不低于 5m**
- 电缆埋地深度**不应小于 0.7m**
- **临时用电时间一般不超过 15 天，特殊情况不应超过 30 天**；用于**动火、受限空间作业**的临时用电时间应和**相应作业时间一致**

</KeyPoint>

<h3>9.9 「受限空间」与「有限空间」对比（易混，新规范）</h3>

| 对比项 | 受限空间（GB 30871-2022） | 有限空间（GB 46768-2025） |
|---|---|---|
| **适用范围** | **危化品企业** | 除危险化学品生产企业、带储存危化经营企业、化工及医药企业、船舶外，**其他行业** |
| **审批** | 所在**基层单位**，作业票 **24 小时** | 企业规定的**作业负责人与作业审批人**（工贸行业涉及硫化氢等中毒窒息的由主要负责人和委托人审批） |
| **培训** | **持证上岗** | **每年至少组织 1 次**专题培训 |
| **隔离** | 与受限空间连通、可能危及安全的管道，应采用**加盲板或拆除一段管道**隔离；**不得用水封或关闭阀门代替盲板** | 更强调有限空间**出入口、作业区域的封闭、警示、隔离和防误入**，属通用行业的作业区域控制 |
| **检测** | 作业前 **30 分钟内**检测；作业中断超过 **60 分钟**应重新气体检测分析 | 强调**初始气体检测、再次气体检测、作业中实时气体监测和持续通风**。作业中断的，作业人再次进入前应**重新气体分析检测** |
| **监测** | 连续检测可燃气体、有毒气体、氧气浓度，并**每 2 小时记录 1 次** | 实时监测，**每 15min 记录 1 个瞬时值** |

**有限空间作业安全管理要点：**

| 管理要求 | 具体内容 |
|---|---|
| **安全培训** | ①作业单位应对本单位**作业审批人、作业负责人、监护人、作业人和应急救援人员**等进行专题安全培训<br/>②发包单位应对本单位**作业审批人、作业现场安全检查人员**等进行专题安全培训<br/>③**每年至少组织 1 次**，人员**考核合格后**方可从事相关工作 |
| **气体检测报警仪** | ①氧气应设定**缺氧报警（19.5%VOL）**和**富氧报警（23.5%VOL）**两级报警值<br/>②**可燃性气体报警值为爆炸下限（LEL）的 10%**<br/>③有毒有害气体报警值为规定的**最高容许浓度或短时间接触容许浓度**<br/>④应**每年至少检定或校准 1 次** |
| **安全电压** | 有限空间内使用的照明灯具额定电压**不应超过 36V**；**金属结构**有限空间作业时**不应超过 24V**；**积水、结露等潮湿环境**作业时**不应超过 12V** |
| **作业审批** | 应经**作业负责人同意**和**作业审批人审批**；涉及**发包作业**的，还应经**发包单位作业审批人**审批 |
| **作业安全** | ①作业过程中应对作业人活动区域进行**实时气体监测**，**每 15min 记录 1 个瞬时值**<br/>②作业过程中应**持续通风**<br/>③作业期间发生下列情况之一时应**立即中断作业、撤离**：作业人出现身体不适；气体检测报警仪报警；安全防护设备设施失效；监护人或作业负责人下达撤离命令；其他可能危及作业人生命安全的情况<br/>④中断作业期间，应在有限空间**出入口设置警示标志**，并采取**防止人员误入的临时封闭措施** |

<Callout type="tip">
**「有限空间」安全电压三档（必考）：**

| 环境 | 照明灯具额定电压 |
|---|---|
| 一般有限空间 | 不超过 **36V** |
| **金属结构** | 不超过 **24V** |
| **积水、结露等潮湿环境** | 不超过 **12V** |

**记忆：越潮湿/导电性越强，电压越低（36 → 24 → 12）**

**监测记录频次区分**：受限空间 **每 2 小时**记录 1 次；有限空间 **每 15min** 记录 1 个瞬时值。
</Callout>

## 第十节 承包商管理与安全生产标准化

<h3 id="s10">10.1 发承包单位的安全职责</h3>

**（1）生产经营单位安全管理责任：**
- 发包工程项目应以**生产经营单位名义**进行，**严禁以某一部门的名义**进行发包
- 应明确**发包工程归口管理部门**，统一对发包工程进行管理
- 要建立完善**承包商安全管理制度**，明确有关职能部门的管理责任
- 要对承包商进行**资质审查**，选择具备相应资质、安全生产条件、安全业绩好的企业作为承包商
- 要对进入本单位的承包商人员进行**全员安全教育**，向承包商进行**作业现场安全交底**。对承包商的安全作业规程、施工方案和应急预案进行审查，对承包商的作业进行**全过程监督**
- 应及时收集承包商信息，建立**安全表现评价准则**，**定期**对承包商的安全业绩进行评价，并将评价结果反馈。对不能履行安全职责甚至发生生产安全事故的承包商，要予以**相应考核直至清退**

**（2）承包商安全管理责任：**
- 承包商从事建设工程的**新建、扩建、改建和拆除**等活动，应具备国家规定的**注册资本、专业技术人员、技术装备和安全生产**等条件，依法取得**相应等级的资质证书**，并在其**资质等级许可的范围内**承揽工程
- 承包商**主要负责人**依法对本单位的安全生产工作**全面负责**
- 应建立健全**安全生产责任制度和安全生产教育培训制度**，制定安全生产规章制度和操作规程，保证安全生产条件所需**资金的投入**，对所承担的工程项目进行**定期和专项安全检查**并做好记录
- 应确保员工在开展各种作业之前**接受与工作有关的安全培训**，确保其了解并执行操作规程等有关安全作业规程
- **同一工程项目或同一施工场所有多个承包商施工**时，生产经营单位应与承包商签订**专门的安全管理协议**或在承包合同中**约定各自的安全生产管理职责**，并对各承包商的安全生产工作**统一协调、管理**

<h3>10.2 承包商资质审查内容</h3>

| 序号 | 业务资质 | 安全资质 |
|---|---|---|
| 1 | 承包商准入审查表 | 承包商安全资质审查表 |
| 2 | 有效的企业资信证明（营业执照、法定代表人证明书、税务登记证、组织机构代码证；银行开户许可证等） | 主要负责人、项目负责人、安全生产管理人员经政府有关部门**安全生产考核合格名单及证书**。施工人员年龄、工种、健康状况等符合要求 |
| 3 | 企业资质证明（施工资质证书、**特种作业操作证**、**安全生产许可证**等） | 安全资质证书（**安全生产许可证**、**职业安全健康管理体系认证证书**等） |
| 4 | 其他资料（近期业绩和表现等） | 企业**近两年的安全业绩**（施工经历、重大安全事故情况档案、事故发生率及原始记录、安全隐患治理情况档案等） |
| 5 | — | **安全管理体系程序文件及有效评审报告** |

<Callout type="tip">
**资质审查的「双线」结构：**

- **业务资质** → 管「**能不能干**」（营业执照、资质证书、业绩）
- **安全资质** → 管「**安全行不行**」（安全考核合格证书、安全业绩、管理体系文件）

**高频考点**：安全业绩要求是「**近两年**」；安全管理体系需要「**程序文件及有效评审报告**」。
</Callout>

<h3>10.3 承包商管理要点</h3>

- 生产经营项目、场所**发包或出租**给其他单位的，应当与承包单位、承租单位签订**专门的安全生产管理协议**，或在承包合同、租赁合同中**约定各自的安全生产管理职责**；生产经营单位对承包单位、承租单位的安全生产工作**统一协调、管理**，**定期进行安全检查**，发现安全问题的应当及时督促整改
- **两个以上生产经营单位在同一作业区域内**进行生产经营活动，可能危及对方生产安全的，应当签订**安全生产管理协议**，明确各自的安全生产管理职责和应当采取的安全措施，并**指定专职安全生产管理人员**进行安全检查与协调
- 涉及定期试验的**工器具、绝缘用具、施工机具、安全防护用品**，应具有检验、试验资质部门出具的**合格的检验报告**
- 生产经营单位应针对承包商等外来人员实行**门禁管理**
- 承包商作业人员进行施工作业前，生产经营单位应将与施工作业有关的**安全技术要求**向承包商作业人员作出**详细说明，双方签字确认**
- 在承包商队伍**进入作业现场前**，发包单位要对其进行**消防安全、设备设施保护及社会治安**方面的教育
- 作业过程中，生产经营单位应派具备**监督管理职能**的人员对承包商作业现场进行**监督检查**，建立监督检查记录

<h3>10.4 安全生产标准化建设</h3>

**（1）理论基础（三道防线）：**

通过构建「**安全风险管控**」「**隐患排查治理**」「**应急处置与救援**」**三道防线**，推动企业安全生产管理模式向**事前预防转型**。

**（2）体系要求：**
采用 **LS-PDCA**（领导-支持-策划-实施-检查-改进）的运行模式。

**（3）大中型企业安全生产标准化管理体系要素：**
设置**一级要素 10 个、二级要素 32 个**。

| 一级要素 | 二级要素 |
|---|---|
| **领导作用** | 安全领导力、安全履职评价 |
| **基础保障** | 组织保障、责任保障、制度保障、资金保障、科技保障 |
| **人员管理** | 人员准入、安全培训、行为管控 |
| **现场管理** | 作业环境与条件、设备设施、危险作业、异常处置、变更管理、相关方管理 |
| **安全风险分级管控** | 危险源辨识、风险评估、风险管控 |
| **事故隐患排查治理** | 事故隐患排查、事故隐患治理、重大事故隐患管理 |
| **应急准备与处置** | 应急准备、应急处置 |
| **策划** | 理念、目标、全员参与、信息沟通 |
| **检查评价** | 检查、绩效评价 |
| **持续改进** | 评审改进 |

<Callout type="tip">
**安全生产标准化核心数字与要点：**

- **三道防线**：安全风险管控 → 隐患排查治理 → 应急处置与救援
- **运行模式**：**LS-PDCA**（领导-支持-策划-实施-检查-改进）
- **要素数量**：一级 **10 个**、二级 **32 个**

**记忆**：三道防线对应「事前预防 → 过程管控 → 事后兜底」
</Callout>

<PracticeFrom section="s10" title="承包商管理与安全生产标准化" />
