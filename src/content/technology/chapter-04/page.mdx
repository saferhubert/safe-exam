## 第一节 火灾爆炸事故机理

<h3 id="s1">1.1 燃烧与火灾</h3>

<KeyPoint examWeight={3}>
**燃烧三要素（燃烧的必要条件）：**

1. **可燃物**（可燃物质）
2. **助燃物**（氧化剂，通常是空气中的氧）
3. **点火源**（引火源、着火源）

**三者同时具备、相互作用，燃烧才能发生。**

**灭火的基本原理（对应破坏三要素）：**
- **隔离** —— 隔离或移去可燃物
- **窒息** —— 隔绝助燃物（降低氧浓度）
- **冷却** —— 降低温度到着火点以下
- **化学抑制** —— 中断链式反应
</KeyPoint>

**燃烧的类型：**

| 类型 | 特点 |
|---|---|
| **闪燃** | 可燃液体表面挥发的蒸气与空气混合，遇火源产生**一闪即灭**的燃烧现象。**闪点**是评定液体火灾危险性的主要依据 |
| **着火** | 可燃物质在空气中与火源接触，达到某一温度时，开始产生**有火焰的燃烧**，并在火源移去后仍能持续 |
| **自燃** | 可燃物质在没有外部火花、火焰等火源的作用下，因**受热或自身发热**并蓄热所产生的自然燃烧 |
| **爆炸** | 物质发生极迅速的物理或化学变化，同时产生大量气体和热量 |

<Callout type="tip">
**关键概念：闪点、燃点、自燃点**

| 概念 | 含义 |
|---|---|
| **闪点** | 可燃液体表面挥发的蒸气与空气形成的混合物，遇火源能发生闪燃的**最低温度**。**闪点是评定液体火灾危险性的主要依据** |
| **燃点（着火点）** | 可燃物质开始持续燃烧所需的最低温度 |
| **自燃点** | 可燃物质在没有外部火源作用下，因自身发热并蓄热而引起自燃的最低温度 |

**火灾危险性排序**：**闪点越低 → 火灾危险性越大**
</Callout>

<h3>1.2 爆炸</h3>

<KeyPoint examWeight={3}>
**爆炸的分类：**

**（1）按爆炸性质分：**
| 类型 | 说明 |
|---|---|
| **物理爆炸** | 物质因状态或压力发生突变而形成的爆炸（如**锅炉爆炸、气瓶爆炸**）。**没有化学反应** |
| **化学爆炸** | 物质发生极迅速的化学反应，产生高温高压而引起的爆炸（如**可燃气体爆炸、粉尘爆炸、炸药爆炸**） |
| **核爆炸** | 原子核裂变或聚变反应 |

**（2）按爆炸反应的相态分：**
| 类型 | 说明 |
|---|---|
| **气相爆炸** | 可燃气体爆炸、可燃液体蒸气爆炸、可燃粉尘爆炸、气体分解爆炸 |
| **凝聚相爆炸** | 炸药爆炸、可燃物与氧化剂混合物爆炸 |
</KeyPoint>

**爆炸极限：**

<KeyPoint examWeight={3}>
**爆炸极限**是指可燃物质（可燃气体、蒸气或粉尘）与空气形成的混合物能发生爆炸的**浓度范围**。

- **爆炸下限（LEL）** —— 能发生爆炸的**最低**浓度
- **爆炸上限（UEL）** —— 能发生爆炸的**最高**浓度

**爆炸极限的影响因素：**
①**初始温度**（温度升高，爆炸极限范围变宽）②**初始压力**（压力升高，爆炸下限降低、上限升高）③**含氧量**（氧含量增加，爆炸极限范围变宽）④**惰性介质**（加入惰性气体，爆炸极限范围变窄）⑤**容器尺寸**（容器直径越小，越不易爆炸）⑥**点火源能量**（能量越大，爆炸极限范围越宽）

**重要结论：**
- 混合物浓度**低于爆炸下限**或**高于爆炸上限**，都不会爆炸
- **爆炸下限越低**，可燃物越容易形成爆炸性混合物，**危险性越大**
- 实际应用中常用 **LEL 的 10%** 作为可燃气体报警值
</KeyPoint>

<Callout type="tip">
**爆炸极限的记忆要点：**

- **温度↑、压力↑、含氧量↑、点火能量↑** → 爆炸极限范围**变宽**（更危险）
- **加入惰性介质、容器直径↓** → 爆炸极限范围**变窄**（更安全）

**应用**：可燃气体检测报警仪的报警值一般设为 **LEL 的 10%~25%**（常用 10%）；动火作业要求氧含量 **≤23.5%**（这个数字与"助燃"相关）。
</Callout>

## 第二节 防火防爆技术

<h3 id="s2">2.1 点火源及其控制</h3>

**点火源的种类：**
①**明火**（最常见）②**电火花和电弧** ③**高温表面** ④**摩擦和撞击** ⑤**自燃发热** ⑥**光辐射** ⑦**化学反应热**

**控制措施：**
- 严格**动火管理**（办理动火作业票）
- 电气设备应采用**防爆型**
- 高温设备表面应**隔热或隔离**
- 禁止**穿钉子鞋、使用铁质工具**（产生摩擦撞击火花）
- 应避免**可燃物堆积**（防止蓄热自燃）

<h3>2.2 爆炸控制</h3>

**控制爆炸的技术措施：**

| 措施 | 说明 |
|---|---|
| **惰性介质保护** | 在爆炸性混合物中加入**惰性气体**（N₂、CO₂等），使混合物中的氧含量降低到**极限氧浓度**以下 |
| **密闭和通风** | 密闭防止可燃物泄漏；通风防止可燃气体积聚 |
| **负压操作** | 使系统处于负压状态，防止可燃物外逸 |
| **可燃物浓度控制** | 将可燃物浓度控制在**爆炸极限范围以外**（低于下限或高于上限） |
| **监测报警** | 设置**可燃气体检测报警仪**，报警值设为 **LEL 的 10%~25%** |
| **消除点火源** | 严格控制明火、电火花、摩擦撞击等 |

<h3>2.3 防火防爆安全装置及技术</h3>

<KeyPoint examWeight={3}>
**防火防爆安全装置（必背）：**

| 装置 | 作用 | 特点 |
|---|---|---|
| **阻火器** | 阻止火焰蔓延、防止回火 | 由**多层金属网或细孔材料**组成，利用**器壁效应**（狭小通道散热）使火焰熄灭。用于**可燃气体管道、油罐呼吸阀**等 |
| **安全阀** | 防止设备超压，**泄压后可重新关闭** | 用于**固定式压力容器**。缺点是**泄压反应慢**（有滞后）、密封性能较差 |
| **爆破片** | 防止设备超压，**一次性泄压** | 超压时**破裂**，不能重复使用。反应**迅速及时** |
| **防爆泄压装置** | 泄放爆炸压力，减轻破坏 | 如**轻质屋盖、泄压门窗、防爆墙** |
| **阻爆器（阻火器的一种）** | 阻止火焰通过管道传播 | 用于可燃气体管道 |
| **火星熄灭器** | 熄灭烟气中的火星 | 用于**汽车排气管、烟囱**等 |
</KeyPoint>

<Callout type="tip">
**阻火器与安全阀的区别：**

- **阻火器** → 阻止**火焰传播**（利用**器壁效应**散热使火焰熄灭），用于**管道**
- **安全阀/爆破片** → 释放**压力**，防止**超压**，用于**容器**

**安全阀 vs 爆破片：**
- 安全阀：**可重新关闭**（可重复使用），但**反应慢**
- 爆破片：**一次性**（破裂后需更换），但**反应快**
</Callout>

## 第三节 烟花爆竹安全技术

<h3 id="s3">3.1 烟花爆竹基本安全知识</h3>

<KeyPoint examWeight={3}>
**烟花爆竹的分类（按药剂和效果）：**

**（1）按产品类别分：** ①烟花 ②爆竹

**（2）按药物（药剂）分类：**
| 药剂类型 | 说明 |
|---|---|
| **黑火药** | 由硝酸钾、硫磺、木炭组成 |
| **烟火药** | 由氧化剂、可燃物、黏合剂等组成，能产生光、色、声响等效果 |

**烟花爆竹的主要危险：**
①**爆炸危险**（药剂本身是爆炸性物质）②**火灾危险** ③**静电危险**（药剂对静电敏感）④**摩擦撞击危险** ⑤**有毒有害**（燃烧产物含有害物质）
</KeyPoint>

**烟花爆竹的安全技术要求：**
- 生产、储存、经营场所应远离**人员密集区和重要设施**
- 作业场所应**严格控制药量**
- 应使用**防爆电气设备**和**防静电措施**
- **严禁**使用铁质工具（防止摩擦撞击火花）
- 作业人员应穿**防静电工作服**
- 应控制**温度和湿度**
- **严禁**超量储存

<Callout type="warning">
**烟花爆竹作业的核心禁令：**

- **严禁**使用**铁质工具**（产生火花）
- **严禁**穿**化纤衣物、钉子鞋**（产生静电、摩擦火花）
- **严禁**超量存放药剂
- **严禁**在作业场所吸烟、使用明火
- 必须使用**防爆电气设备**

**静电是烟花爆竹作业的重要危险源**（药剂对静电敏感）。
</Callout>

## 第四节 民用爆炸物品安全技术

<h3 id="s4">4.1 民用爆炸物品生产安全基础知识</h3>

**民用爆炸物品的种类：**
①**工业炸药**（铵梯炸药、乳化炸药、铵油炸药等）②**工业雷管**（火雷管、电雷管、导爆管雷管等）③**工业索类**（导火索、导爆索、导爆管等）④**其他**（起爆具、震源药柱等）

**主要危险：**
①**爆炸危险**（本身是爆炸性物质）②**火灾危险** ③**静电危险** ④**摩擦撞击危险** ⑤**中毒危险**（部分炸药含有毒物质）

**安全技术措施：**
- 生产、储存场所应**严格隔离**，保持安全距离
- 应控制**作业人员数量和药量**（定员定量）
- 应使用**防爆电气设备**
- 应严格**防静电、防摩擦撞击**
- 应设置**防护屏障（防爆墙）**
- **严禁**烟火和明火
- 应严格**出入库管理**

<Callout type="tip">
**民爆物品安全的「四防」：**

1. **防静电** —— 穿防静电服、接地
2. **防摩擦撞击** —— 禁用铁质工具
3. **防火** —— 严禁烟火
4. **防超量** —— 定员定量

**「定员定量」**是民爆行业最核心的安全管理制度。
</Callout>

## 第五节 消防设施与器材

<h3 id="s5">5.1 消防设施</h3>

**常用消防设施：**
①**消防给水系统**（消火栓、消防水池）②**自动喷水灭火系统** ③**泡沫灭火系统** ④**气体灭火系统** ⑤**干粉灭火系统** ⑥**火灾自动报警系统**

<h3>5.2 消防器材（灭火器）</h3>

<KeyPoint examWeight={3}>
**灭火器的类型与适用火灾（必背）：**

**火灾分类：**
| 类别 | 燃烧物质 |
|---|---|
| **A 类火灾** | **固体**物质火灾（木材、纸张、棉麻等） |
| **B 类火灾** | **液体或可熔化的固体**物质火灾（汽油、煤油、沥青等） |
| **C 类火灾** | **气体**火灾（煤气、天然气、甲烷等） |
| **D 类火灾** | **金属**火灾（钾、钠、镁、铝镁合金等） |
| **E 类火灾** | **带电**火灾（物体带电燃烧） |

**灭火器的适用范围：**
| 灭火器类型 | 适用火灾 |
|---|---|
| **水型灭火器** | **A 类**（固体）。**不能用于带电火灾和油类火灾** |
| **泡沫灭火器** | **A 类、B 类**。**不能用于带电火灾** |
| **干粉灭火器** | **A、B、C 类**，以及**带电火灾（E 类）**。用途最广泛 |
| **二氧化碳灭火器** | **B、C 类**，以及**带电火灾（E 类）**。适用于**精密仪器、贵重设备** |
| **卤代烷灭火器** | 适用于**精密仪器、计算机房**（已逐步淘汰） |
</KeyPoint>

<Callout type="tip">
**灭火器选用的记忆要点：**

- **水** → 只能灭 **A 类**（固体）；**绝不能**用于带电、油类
- **泡沫** → 灭 **A、B 类**；**不能**用于带电
- **干粉** → 灭 **A、B、C、E**（**用途最广**）
- **二氧化碳** → 灭 **B、C、E**（适合**精密仪器、贵重设备、计算机房**）

**易错点**：
- 带电火灾（E 类）只能用**干粉、二氧化碳**（不能用水和泡沫）
- 金属火灾（D 类）需用**专用灭火剂**（如干砂、氯化钠干粉）
</Callout>

## 第六节 燃烧与爆炸灾害定量评价

<h3 id="s6">6.1 爆炸灾害定量评价</h3>

**爆炸破坏作用的等级（2025 年真题考点）：**

<KeyPoint examWeight={2}>
**建筑物经受爆炸冲击波作用后的破坏等级：**

| 破坏等级 | 破坏程度 |
|---|---|
| **一级破坏** | 仅**门窗玻璃部分或全部破坏**，**墙体无裂缝** |
| **二级破坏** | 门窗玻璃**全部破坏**，部分门窗扇损坏，砖墙出现**小裂缝** |
| **三级破坏** | **门窗大部分破坏**，砖墙有**较大裂缝但无明显倾斜** |
| **四级破坏** | 门窗大部分破坏，砖墙有**较大裂缝且出现倾斜** |
</KeyPoint>

<Callout type="info">
**2025 年真题解析（爆炸破坏等级）：**

题目问「建筑物经受爆炸冲击波作用后破坏等级和破坏程度的对应关系中，正确的是」，答案选「**四级破坏——门窗大部分破坏，砖墙有较大裂缝和倾斜**」。

**其他选项的错误点**：
- 「一级破坏——门窗玻璃部分或全部破坏，砖墙有小裂缝」→ 错，一级破坏**墙体无裂缝**
- 「二级破坏——门窗小部分破坏，砖墙出现小裂缝倾斜」→ 错，二级破坏**门窗玻璃全部破坏**
- 「三级破坏——门窗小部分破坏，砖墙有较大裂缝和倾斜」→ 错，三级破坏**无明显倾斜**

**记忆规律**：等级越高，破坏越严重；**倾斜是三级与四级的分界线**。
</Callout>

**惰性气体转换系数 K（2025 年超纲考点）：**

转换系数 K（单位 m³/m³）从大到小排序：**CO₂（约 5.0）＞ He（约 3.0）＞ Ar（约 1.7）**

<Callout type="tip">
**记忆**：**CO₂ ＞ He ＞ Ar**

（二氧化碳最常用、效率最高；氦气次之；氩气最低）
