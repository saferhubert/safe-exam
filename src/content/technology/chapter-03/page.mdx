## 第一节 特种设备的基础知识

<h3 id="s1">1.1 特种设备的范围</h3>

**特种设备**是指对人身和财产安全有较大危险性的**锅炉、压力容器（含气瓶）、压力管道、电梯、起重机械、客运索道、大型游乐设施、场（厂）内专用机动车辆**，以及法律、行政法规规定适用本法的其他特种设备。

<Callout type="tip">
**特种设备八大类记忆口诀：**

**锅容管、电起客、游厂车**

（锅炉、压力容器、压力管道、电梯、起重机械、客运索道、大型游乐设施、场（厂）内专用机动车辆）

**承压类 vs 机电类的划分：**
- **承压类**：锅炉、压力容器、压力管道（承受压力）
- **机电类**：电梯、起重机械、客运索道、大型游乐设施、场（厂）内专用机动车辆（机械运动）
</Callout>

**特种设备的分类标准（划分界限）：**

| 类别 | 划分标准 |
|---|---|
| **锅炉** | 承压蒸汽锅炉：容积 ≥30L 且压力 ≥0.1MPa；承压热水锅炉：出口水压 ≥0.1MPa 且额定功率 ≥0.1MW；有机热载体锅炉：功率 ≥0.1MW |
| **压力容器** | 固定式与移动式容器：①最高工作压力 ≥0.1MPa ②容积 ≥30L 且内直径 ≥150mm ③介质为气体、液化气体和最高工作温度 ≥标准沸点的液体<br/>气瓶：①公称工作压力 ≥0.2MPa ②压力与容积的乘积 ≥1.0MPa·L ③介质为气体、液化气体和标准沸点 ≤60℃ 液体<br/>**氧舱：只要是氧舱就是特种设备** |
| **压力管道** | ①压力 ≥0.1MPa ②介质为气体、液化气体、蒸汽或可燃、易爆、有毒、有腐蚀性、最高工作温度 ≥标准沸点的液体 ③公称直径 ≥50mm |
| **电梯** | 载人（货）电梯、自动扶梯、自动人行道 |
| **起重机械** | 升降机：额定起重量 ≥0.5t；起重机：①提升高度 ≥2m ②额定起重量 ≥3t（塔式起重机额定起重力矩 ≥40t·m，装卸桥生产率 ≥300t/h）；机械式停车设备：层数 ≥2 层 |
| **客运索道** | 客运架空索道、客运缆车、客运拖牵索道（非公用和专用于单位内部通勤的除外） |
| **大型游乐设施** | ①最大运行线速度 ≥2m/s ②或运行高度 ≥2m（用于体育运动、文艺演出和非经营活动的除外） |
| **场（厂）内专用机动车辆** | 机动工业车辆（叉车）；非公路用旅游观光车辆 |

## 第二节 锅炉安全技术

<h3 id="s2">2.1 锅炉安全附件</h3>

<KeyPoint examWeight={2}>
**锅炉三大安全附件（必考）：**

| 附件 | 作用 |
|---|---|
| **安全阀** | 当锅炉压力超过规定值时**自动开启泄压**，防止超压爆炸。是锅炉最重要的安全附件 |
| **压力表** | 指示锅炉内蒸汽或水的**压力** |
| **水位计（水位表）** | 指示锅炉内**水位**高低，防止缺水或满水事故 |

**其他安全附件**：温度计、排污阀、止回阀、减压阀等。
</KeyPoint>

<h3>2.2 锅炉使用安全技术</h3>

- 锅炉**安全阀**应定期校验，确保灵敏可靠
- 锅炉运行中应**密切监视水位和压力**，防止**缺水**、**满水**、**超压**
- 锅炉应定期进行**水质处理**，防止结垢和腐蚀
- 锅炉应按规定进行**定期检验**
- 锅炉**点火前**应检查安全附件是否完好
- 锅炉**停炉**应按规程操作，防止发生事故

**锅炉事故类型：**
①**缺水事故**（最危险，可能导致爆炸）②**满水事故** ③**汽水共腾** ④**炉膛爆炸** ⑤**受热面管子破裂** ⑥**锅炉超压**

<Callout type="warning">
**锅炉缺水事故是最危险的事故**，如果严重缺水后**盲目上水**，会导致锅炉**急剧汽化、压力骤增而爆炸**。因此：
- 发现严重缺水，**严禁立即上水**
- 应先**紧急停炉**，待锅炉冷却后再处理
</Callout>

## 第三节 气瓶安全技术

<h3 id="s3">3.1 气瓶概述</h3>

**气瓶**：容积**不超过 3000L**，用于储存和运输压缩气体、液化气体、溶解气体、吸附气体的**可重复充装的可移动的容器**。

**（1）瓶装气体分类（按气体在气瓶内的物理状态和临界温度）：**

| 类别 | 说明 |
|---|---|
| **压缩气体** | 在 **-50℃** 时加压后完全是气态的气体，包括临界温度 **Tc ≤ -50℃** 的气体，也称**永久气体** |
| **高（低）压液化气体** | 在温度**高于 -50℃** 时加压后**部分呈液态**的气体。包括 Tc 在 **-50~65℃** 的**高压**液化气体，和 Tc **高于 65℃** 的**低压**液化气体 |
| **低温液化气体** | 运输过程中由于**深冷低温**而部分呈液态的气体，Tc 一般**低于或等于 -50℃**，也称深冷/冷冻液化气体 |
| **溶解气体** | 在一定压力、温度条件下**溶解于气瓶内溶剂**中的气体。易分解或聚合的可燃气体 |
| **吸附气体** | 在一定压力、温度条件下**吸附于吸附剂**中的气体 |
| **混合气体与标准气体** | — |

**（2）气瓶分类：**

| 分类依据 | 类别 |
|---|---|
| **按瓶体结构（5 类）** | ①无缝气瓶 ②焊接气瓶 ③纤维缠绕气瓶 ④低温绝热气瓶 ⑤内装填料气瓶 |
| **按公称工作压力（2 类）** | **高压气瓶**：公称工作压力 **≥10MPa**；**低压气瓶**：公称工作压力 **＜10MPa** |
| **按公称容积（3 类）** | **小容积**：≤**12L**；**中容积**：＞12L 且 ≤**150L**；**大容积**：＞**150L** |
| **按用途（6 类）** | ①工业用 ②医用 ③燃气 ④车用 ⑤呼吸器用 ⑥消防灭火用 |

**（3）气瓶附件：**

<KeyPoint examWeight={3}>
**瓶阀的关键要求（高频考点）：**

1. 瓶阀上与气瓶连接的**螺纹**，与瓶体螺纹匹配并保证密封可靠性
2. 瓶阀**出气口的连接型式和尺寸**，设计成能防止气体**错装、错用**的结构
   - **盛装助燃和不可燃气体**瓶阀的出气口螺纹为**右旋**
   - **可燃气体**瓶阀的出气口螺纹为**左旋**
3. 工业用非重复充装焊接气瓶瓶阀设计成**不可重复充装**的结构，瓶阀与瓶体采用**焊接**方式
4. 公称容积 **＞100L** 的液化石油气瓶使用的**气相瓶阀**，宜设计成带有**液位限定功能**或带有**电子防伪识读功能**的直阀或角阀，**液相瓶阀**宜设计成**单向阀**
5. **与乙炔接触的瓶阀材料，选用含铜量小于 65% 的铜合金**（质量比）—— 因为铜会与乙炔起反应生成**乙炔铜**，乙炔铜是一种**爆炸性化合物**
6. 盛装**易燃气体**的气瓶瓶阀**手轮**，选用**阻燃材料**制造
7. 盛装**氧气或其他强氧化性气体**的气瓶瓶阀**非金属密封材料**，具有**阻燃性和抗老化性**
</KeyPoint>

<Callout type="warning">
**三个高频易错点：**

1. **螺纹旋向**：**助燃和不可燃气体 → 右旋**；**可燃气体 → 左旋**
   （记忆：「可左助右」——可燃气左旋，助燃/不可燃气右旋）
2. **乙炔瓶阀含铜量＜65%** —— 因铜与乙炔生成**爆炸性乙炔铜**
3. **燃气瓶手轮用阻燃材料**；**氧气瓶密封材料需阻燃抗老化**
</Callout>

**瓶帽和保护罩：**

- **瓶帽**是装在气瓶顶部、阀门之外的帽罩式保护附件，功能在于避免气瓶在搬运、运输或使用过程中受碰撞或冲击损伤阀门
- **为防止气体泄漏或由于超压泄放造成瓶帽爆炸，瓶帽上要开有对称的泄气孔**。泄气孔**对称开设**是为了避免气体由一侧排出产生的反作用使气瓶倾倒或旋转
- **保护罩**是保护瓶帽、瓶阀或易熔塞免受撞击而设置的**敞口屏罩式**零件，也可兼作提升零件，所有保护罩应为**不可拆卸**结构

**瓶帽和保护罩的要求：**
1. **无缝气瓶**出厂时，应装配不影响瓶阀手轮正常使用的**保护罩**，并且**不得装配螺纹式瓶帽**
2. 公称容积 **≥10L** 的钢质焊接气瓶（含溶解乙炔气瓶），应装配**不可拆卸的保护罩**或**固定式瓶帽**
3. 保护罩或固定式瓶帽应具有良好的抗撞击性，**不得用铸铁制造**；公称容积 ≤**5L** 的钢质无缝气瓶和 ≤**15L** 的铝合金无缝气瓶的保护罩，可以用**工程塑料**制造

**（4）安全泄压装置（重点）：**

<KeyPoint examWeight={3}>
**安全泄压装置的主要作用**：**（甚至是唯一作用）是保护气瓶在遇到周围发生火灾时，不会因瓶体受热、瓶内温度升高过快而造成气瓶爆炸。**

**四种类型：**

| 类型 | 特点与适用 |
|---|---|
| **易熔合金塞装置** | 结构**简单**；通过**控制温度**控制瓶内温升压力，**只适用于气瓶**，不适用于固定式容器 |
| **爆破片装置** | 由爆破片和夹持器组成。压力增至规定限定值（一般为气瓶水压试验压力）时爆破片破裂排气。用于永久气体气瓶的爆破片一般装配在**气瓶阀门**上 |
| **安全阀** | 广泛用于**固定式压力容器**。特点是机构简单、紧凑，且**可重新关闭**。缺点是**泄压反应慢**（开启有滞后）、对介质洁净度要求高、**密封性能差**（各类中最差）。**一般气瓶都没有安装这种泄压装置** |
| **爆破片－易熔塞复合装置** | 由爆破片与易熔塞**串联**组装，易熔合金塞装设在爆破片**排放一侧**。兼具两者优越性，尤其**密封性能更佳**（双重密封机构）。一般用于对密封性能要求特别严格的气瓶（如盛装三氟化硼、氯化氢、硅烷、氟乙烯、溴化氢等气体的气瓶） |

**易熔合金塞装置的公称动作温度：**
| 适用气瓶 | 公称动作温度 |
|---|---|
| **溶解乙炔**气瓶 | **100℃** |
| 公称工作压力 **≤3.45MPa** 的气瓶（除溶解乙炔外） | **70℃** |
| 公称工作压力 **＞3.45MPa 且 ≤30MPa** 的气瓶 | **102.5℃** |
| **车用压缩天然气**气瓶 | **110℃** |
</KeyPoint>

**安全泄压装置的选用原则（8 条）：**
1. **应当装设**的：车用气瓶、溶解乙炔气瓶、焊接绝热气瓶、液化气体气瓶集束装置，以及长管拖车和管束式集装箱用大容积气瓶
2. **禁止装设**的：盛装**剧毒气体、自燃气体的气瓶**
3. 盛装**有毒气体**的气瓶**不应当单独装设安全阀**；盛装**高压有毒气体**的气瓶应当选用**爆破片－易熔合金塞复合装置**
4. **燃气气瓶**和**氧气、氮气以及惰性气体气瓶**，**一般不装设**安全泄压装置
5. 盛装**易于分解或聚合的可燃气体、溶解乙炔气体**的气瓶，应当装设**易熔合金塞装置**
6. 盛装**液化天然气及其他可燃气体的低温绝热气瓶内胆**，至少装设 **2 只安全阀**；盛装其他低温液化气体的低温绝热气瓶，应当装设**爆破片装置和安全阀**
7. **车用液化石油气钢瓶、车用二甲醚钢瓶**，应装设带安全阀的组合阀或分立的安全阀；**车用压缩天然气气瓶**，应装设**爆破片－易熔合金塞串联复合装置或玻璃泡装置**
8. **工业用非重复充装焊接钢瓶**应当装设**爆破片**

<Callout type="tip">
**安全泄压装置的装设部位（易考）：**

- **无缝气瓶** → 装设在**瓶阀**上
- **焊接气瓶** → **单独设置在气瓶封头上**或装设在瓶阀或阀座上
- **工业用非重复充装焊接钢瓶**的爆破片 → **焊接在气瓶封头上**
- **低温绝热气瓶** → 装设在气瓶**外壳的封头部位**
- **溶解乙炔气瓶** → 易熔合金塞装设在**上封头、阀座或瓶阀**上
- **爆破片－易熔合金塞复合装置**中的爆破片 → 置于与**瓶内介质接触的一侧**

**安全阀开启压力**：不小于气瓶水压试验压力的 **75%**，并且不大于气瓶水压试验压力。
</Callout>

**（5）防震圈：**

防震圈是套在气瓶外面的**弹性物质**，主要功能是**防止气瓶受到直接冲撞**，同时有利于保护气瓶外表面漆色、标字和色环等识别标记，减少瓶身磨损，延长使用寿命。

**防震圈的基本要求：**①材料应具有一定的**抗拉强度** ②具有一定的**弹性和塑性**（不会自动脱落）③具有一定的**硬度**（能经受撞击）

**（6）气瓶的颜色标记和钢印标记：**

- **颜色标志**：涂敷在气瓶外表面的**瓶色、字样、字色以及色环**，是识别气瓶内所充装气体的标志。目的是从颜色上迅速辨别盛装某种气体的气瓶和瓶内气体的性质（可燃性、毒性），**避免错装和错用**；另外反射阳光和热量，防止气瓶外表面生锈
- **钢印标志**：识别气瓶的**重要依据**，包括**制造钢印标志**和**检验钢印标志**。检验钢印包括**检验机构代号、检验日期、下次检验日期**等

## 第四节 压力容器安全技术

<h3 id="s4">4.1 压力容器基础知识</h3>

**压力容器的分类：**

| 分类依据 | 类别 |
|---|---|
| 按压力等级 | 低压、中压、高压、超高压容器 |
| 按工艺用途 | 反应容器、换热容器、分离容器、储存容器 |
| 按安装方式 | 固定式、移动式 |

<h3>4.2 压力容器安全附件、仪表及安全技术</h3>

**压力容器的主要安全附件：**
①**安全阀** ②**爆破片** ③**安全联锁装置** ④**压力表** ⑤**液位计** ⑥**温度计** ⑦**紧急切断装置**

<Callout type="tip">
**压力容器安全附件的「三大类」记忆：**

- **泄压装置**：安全阀、爆破片（防止超压）
- **计量装置**：压力表、液位计、温度计（监视运行参数）
- **联锁/切断装置**：安全联锁、紧急切断（异常时自动动作）
</Callout>

## 第五节 压力管道安全技术

<h3 id="s5">5.1 压力管道基础知识</h3>

**压力管道的分类：**
- 按用途：**长输管道**、**公用管道**、**工业管道**
- 按压力等级：低压、中压、高压管道

**压力管道的主要事故：**

- 应设置**压力、温度监测装置**
- 管道应进行**定期检验**

- 应设置**支吊架**，防止管道变形

## 第六节 起重机械安全技术

<h3 id="s6">6.1 起重机械使用安全技术</h3>

<KeyPoint examWeight={3}>
**起重机械的主要安全装置（必背）：**

| 安全装置 | 作用 |
|---|---|
| **限位器** | **上升极限位置限制器**（防吊钩过卷扬）、**运行极限位置限制器**（防起重机越轨） |
| **制动器** | 控制吊物下降速度，**制动失灵易造成重物坠落** |
| **缓冲器** | 吸收起重机碰撞能量，防止撞击损坏 |
| **防碰撞装置** | 防止多台起重机相互碰撞 |
| **起重量限制器（超载限制器）** | 防止超载，**超过额定起重量时自动切断起升动力** |
| **力矩限制器** | 用于**塔式起重机、门座式起重机**等，防止超载倾覆 |
| **支腿回缩锁定装置** | 防止支腿意外回缩 |
| **防后倾装置** | 防止臂架后倾 |
| **夹轨器（防风抗滑装置）** | 防止起重机在风力下滑移 |
</KeyPoint>

**起重机械的安全操作要点：**
- 作业前应**检查安全装置**是否完好
- **严禁超载**吊运
- **严禁**用吊钩直接缠绕吊物
- **严禁**斜拉、斜吊
- **严禁**起吊埋在地下的重物
- **严禁**在吊物下方站立或通过
- **六级及以上大风**不应露天作业
- 停工和休息时，**不应将吊物、吊笼、吊具和吊索悬在空中**

<Callout type="tip">
**起重机械安全装置的记忆线索：**

- **防过卷扬** → 上升极限位置限制器
- **防越轨** → 运行极限位置限制器
- **防超载** → 起重量限制器（塔式/门座用**力矩限制器**）
- **防碰撞** → 缓冲器、防碰撞装置
- **防风滑** → 夹轨器

**易忽略的**：**力矩限制器**主要用于**塔式起重机和门座式起重机**（因为这类起重机的倾覆力矩是主要危险）。
</Callout>

## 第七节 场（厂）内专用机动车辆安全技术

<h3 id="s7">7.1 场（厂）内专用机动车辆使用安全技术</h3>

**场（厂）内专用机动车辆的类别：**
①**机动工业车辆（叉车）** —— 平衡重式叉车、前移式叉车、侧面式叉车、插腿式叉车、托盘堆垛车、三向堆垛式叉车
②**非公路用旅游观光车辆** —— 观光车和观光列车

**主要危险：**
①**碰撞**（与人员、建筑物碰撞）②**倾翻**（超载、转弯过急、坡道行驶）③**挤压**（叉车货叉、车辆与人员之间）④**坠落**（人员从车上坠落）

**安全技术措施：**
- 驾驶员应**持证上岗**
- **严禁超载、超速**
- 转弯、坡道应**减速慢行**
- 货叉上**严禁载人**
- 应设置**警示装置、后视镜、灯光**
- 应定期**检验**

<Callout type="warning">
**叉车安全的核心禁令：**

- **严禁**货叉载人
- **严禁**超载
- 行驶时应**货叉降低**
- 转弯、坡道**减速**
- 门架前倾时**严禁**提升货物

**叉车倾翻的主要原因**：超载、转弯过急、坡道行驶、货物装载偏斜。
</Callout>

## 第九节 大型游乐设施安全技术

<h3 id="s9">9.1 大型游乐设施使用安全管理及其安全装置</h3>

**大型游乐设施**：①最大运行线速度 **≥2m/s** ②或运行高度 **≥2m**（用于体育运动、文艺演出和非经营活动的除外）

<KeyPoint examWeight={2}>
**大型游乐设施的主要安全装置：**

| 安全装置 | 作用 |
|---|---|
| **安全带** | 防止乘客在运行中甩出 |
| **安全压杠（压肩）** | 限制乘客身体移动，防止甩出 |
| **止逆装置** | 防止设备逆转 |
| **制动装置** | 控制运行速度，防止失控 |
| **限速装置** | 限制运行速度 |
| **超速保护装置** | 超速时自动制动 |
| **行程限位装置** | 限制运行范围 |

**安全管理的核心要求：**
- 应经**检验合格**后方可投入运营
- 应制定**安全操作规程**
- 应设置**警示标志**
- 乘客应正确使用**安全装置**
- 应定期进行**检验和维护**
</KeyPoint>
