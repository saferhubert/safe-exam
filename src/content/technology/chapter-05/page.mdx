## 第一节 危险化学品的分类与主要危害

<h3 id="s1">1.1 危险化学品的分类</h3>

<KeyPoint examWeight={3}>
**危险化学品按危险特性分为 8 大类：**

1. **爆炸品**
2. **压缩气体和液化气体**
3. **易燃液体**
4. **易燃固体、自燃物品和遇湿易燃物品**
5. **氧化剂和有机过氧化物**
6. **有毒品**
7. **放射性物品**
8. **腐蚀品**
</KeyPoint>

**危险化学品的主要危险特性：**

| 特性 | 说明 |
|---|---|
| **燃烧性** | 易燃液体、易燃固体、可燃气体等易燃烧 |
| **爆炸性** | 爆炸品、可燃气体与空气形成爆炸性混合物等 |
| **毒害性** | 有毒品可通过吸入、食入、皮肤吸收进入人体造成中毒 |
| **腐蚀性** | 腐蚀品能灼伤人体组织并对金属等物品造成损坏 |
| **放射性** | 放射性物品能放射出射线危害人体健康 |

### 1.2 化学品安全技术说明书（SDS）和安全标签

<KeyPoint examWeight={3}>
**化学品安全技术说明书（SDS）的内容（16 项）：**

1. 化学品及企业标识
2. **成分/组成信息**
3. **危险性概述**
4. **急救措施**
5. **消防措施**
6. **泄漏应急处理**
7. **操作处置与储存**
8. **接触控制/个体防护**
9. **理化特性**
10. **稳定性和反应活性**
11. **毒理学信息**
12. **生态学信息**
13. **废弃处置**
14. **运输信息**
15. **法规信息**
16. 其他信息

**化学品安全标签的内容：**
①**化学品标识**（名称、分子式/结构式）②**象形图** ③**信号词**（危险/警告）④**危险性说明** ⑤**防范说明** ⑥**供应商标识** ⑦资料参阅提示语
</KeyPoint>

<Callout type="tip">
**SDS 与安全标签的区别：**

- **SDS（安全技术说明书）** → **给专业人员看**的详细技术文件，**16 项内容**
- **安全标签** → **贴在包装上**，简明扼要，含**象形图、信号词、危险性说明**

**记忆锚点**：SDS 是"**说明书**"（详细），标签是"**标识**"（简明）。

**高频考点**：SDS 必须包含**急救措施、消防措施、泄漏应急处理、个体防护**——这四个是应急处置的核心项。
</Callout>

## 第二节 危险化学品燃烧爆炸事故的危害

<h3 id="s2">2.1 燃烧爆炸的分类与破坏作用</h3>

**危险化学品燃烧爆炸的分类：**
①**可燃气体爆炸** ②**可燃液体蒸气爆炸** ③**可燃粉尘爆炸** ④**炸药爆炸** ⑤**容器爆炸** ⑥**管道爆炸**

**爆炸的破坏作用：**
①**冲击波的破坏作用**（最主要）②**碎片打击** ③**火灾** ④**有毒气体扩散** ⑤**二次爆炸**

**影响爆炸破坏作用的因素：**
①爆炸物数量 ②爆炸物性质 ③爆炸环境（是否受限空间）④距爆源距离等

## 第三节 危险化学品事故的控制和防护措施

<h3 id="s3">3.1 事故的控制和防护措施</h3>

<KeyPoint examWeight={3}>
**控制与防护措施的核心逻辑：围绕「燃烧三要素」和「爆炸条件」展开**

| 措施类别 | 具体内容 |
|---|---|
| **取代或替代** | 用**不燃或难燃**的物质取代可燃物质；用**无毒或低毒**物质取代剧毒物质 |
| **密闭** | 将产生可燃、有毒气体的设备**密闭**，防止泄漏 |
| **通风** | 稀释和排出可燃、有毒气体，防止积聚 |
| **惰性介质保护** | 加入 **N₂、CO₂** 等惰性气体，使氧含量降到极限氧浓度以下 |
| **控制可燃物浓度** | 将可燃物浓度控制在**爆炸极限范围以外** |
| **消除点火源** | 严格动火管理；使用**防爆电气设备**；防静电、防摩擦撞击 |
| **监测报警** | 设置**可燃气体检测报警仪**（报警值设为 LEL 的 10%~25%） |
| **安全装置** | 设置**安全阀、爆破片、阻火器、防爆泄压装置** |
| **限制储存量** | 严格控制危险化学品的储存量 |
| **个体防护** | 配备符合要求的**个体防护用品** |
</KeyPoint>

<Callout type="tip">
**措施的记忆主线：「防泄漏、控浓度、去火源、加防护」**

1. **防泄漏** → 密闭、通风
2. **控浓度** → 惰性介质、控制浓度在爆炸极限外
3. **去火源** → 动火管理、防爆电气、防静电
4. **加防护** → 安全装置、监测报警、个体防护
</Callout>

## 第四节 危险化学品储存、运输与包装安全技术

<h3 id="s4">4.1 危险化学品储存的基本要求</h3>

<KeyPoint examWeight={3}>
**危险化学品的三种储存方式（必背）：**

| 储存方式 | 定义 |
|---|---|
| **隔离储存** | 在同一房间或同一区域内，不同的物料之间**分开一定距离**，非禁忌物料间用**通道**保持空间，隔开储存 |
| **隔开储存** | 在同一建筑或同一区域内，用**隔板或墙**，将其与禁忌物料**分离开**的储存方式 |
| **分离储存** | 在不同的**建筑物**或远离所有建筑的外部区域内的储存方式 |

**储存的基本要求：**
- 危险化学品必须储存在**专用仓库、专用场地或专用储存室**内，储存地点应设置明显标志
- 应根据危险化学品的**种类和特性**分区、分类、分库储存
- **禁忌物料不得混存**（如氧化剂与还原剂、酸与碱）
- 储存场所应**通风良好**，配备**消防器材**
- 应设置**防雷、防静电**措施
- 应严格控制**储存温度和湿度**
- 应**定期检查**，发现问题及时处理
</KeyPoint>

<Callout type="tip">
**三种储存方式的区分（易混）：**

| 方式 | 分隔手段 |
|---|---|
| **隔离储存** | **一定距离** + 通道 |
| **隔开储存** | **隔板或墙** |
| **分离储存** | **不同的建筑物** |

**记忆**：隔离（距离）→ 隔开（隔板墙）→ 分离（不同建筑），管控严格程度递增。
</Callout>

<h3>4.2 危险化学品运输与包装安全技术</h3>

**运输安全要求：**
- 运输车辆应取得**危险货物运输许可证**
- 驾驶员、押运员应**持证上岗**
- 车辆应设置**明显的危险货物标志**
- 应配备**灭火器材**和**应急处理器材**
- **严禁**超装、超载
- **严禁**混装禁忌物品
- 应避开**人员密集区和重要设施**
- **严禁**在高温时段运输易挥发、易燃的危险化学品

**包装安全要求：**
- 包装容器应符合**国家标准**
- 包装应**牢固、密封**，能承受运输过程中的冲击和振动
- 包装上应有**安全标签**
- 应根据危险化学品的**性质**选择合适的包装材料

## 第五节 危险化学品经营的安全要求

<h3 id="s5">5.1 经营企业的条件和要求</h3>

**危险化学品经营企业应具备的条件：**
①有符合**国家标准**的经营场所、设施、建筑物
②从业人员经**专业培训并考核合格**
③有**健全的安全管理制度**和**岗位操作规程**
④有**应急预案**和必要的**应急救援器材**
⑤依法取得**危险化学品经营许可证**

**经营场所的要求：**
- 经营场所应与**居民区、学校、医院**等保持**安全距离**
- 应有**明显的安全警示标志**
- 应配备**消防器材**
- 应**限量存放**危险化学品
- **严禁**在经营场所内**超量储存**或**混存禁忌物品**

<Callout type="tip">
**经营安全的核心要求：**

- **持证经营**（危险化学品经营许可证）
- **人员持证**（从业人员考核合格）
- **制度健全**（安全管理制度 + 岗位操作规程）
- **应急到位**（应急预案 + 应急救援器材）
- **距离合规**（与人员密集场所保持安全距离）
</Callout>

## 第六节 泄漏控制与销毁处置技术

<h3 id="s6">6.1 泄漏控制</h3>

<KeyPoint examWeight={2}>
**泄漏控制的处置程序：**

1. **报警与报告** —— 立即报告有关部门，启动应急预案
2. **划定警戒区** —— 根据泄漏量和扩散范围划定警戒区，**疏散无关人员**
3. **切断泄漏源** —— 在确保安全的前提下，采取措施**堵漏、关阀、倒罐**
4. **控制扩散** —— 采取**喷雾水稀释、覆盖、围堤**等措施控制扩散
5. **消除点火源** —— 严禁烟火，关闭电源，使用**防爆工具**
6. **个体防护** —— 处置人员必须佩戴**符合要求的防护用品**
7. **收集处理** —— 对泄漏物进行**收集、中和、稀释、焚烧**等处理
8. **监测与善后** —— 持续监测，确认安全后解除警戒

**液态泄漏的处理措施：**
- 用**砂土、蛭石**等惰性材料吸收
- 用**泡沫覆盖**减少挥发
- 用**围堤**防止扩散
- 收集后**妥善处理**

**气态泄漏的处理措施：**
- 用**喷雾水**稀释、溶解
- 用**排风机**将气体排出
- 避免在**下风向**作业
- 设置**警戒区**
</KeyPoint>

<h3>6.2 销毁处置</h3>

**销毁处置的方法：**
①**焚烧法** ②**中和法** ③**氧化还原法** ④**填埋法**（需符合环保要求）⑤**化学分解法**

**处置原则：**
- 应根据危险化学品的**性质**选择合适的处置方法
- 处置过程应**防止二次污染**
- 应遵守**环保法规**要求
- **严禁**随意倾倒、排放

## 第七节 危险化学品的危害及防护

<h3 id="s7">7.1 危险化学品的危害及防护</h3>

<KeyPoint examWeight={2}>
**个人防护装备的选择：**

| 危害类型 | 防护装备 |
|---|---|
| **有毒气体/蒸气** | **防毒面具**（过滤式或隔绝式）、防护服 |
| **腐蚀性物质** | **防酸碱**防护服、防护手套、防护眼镜/面罩 |
| **粉尘** | **防尘口罩**、防护服 |
| **放射性** | **防辐射**防护服、防护眼镜 |
| **高温** | 隔热防护服、手套 |
| **噪声** | 耳塞、耳罩 |

**急性中毒的急救原则：**
1. **迅速脱离现场**（将中毒者移至**上风向、空气新鲜处**）
2. **保持呼吸道通畅**（解开衣领，清除口鼻异物）
3. **脱去污染衣物**（皮肤污染时用大量清水冲洗）
4. **对症处理**（呼吸停止时立即进行**人工呼吸**；心跳停止时立即**心肺复苏**）
5. **及时送医**（携带化学品安全技术说明书）
</KeyPoint>

<Callout type="warning">
**中毒急救的关键要点：**

- **迅速脱离现场** → 移至**上风向、空气新鲜处**
- **皮肤接触** → 用**大量清水冲洗**（至少 15 分钟）
- **眼睛接触** → 用**大量清水或生理盐水冲洗**（提起眼睑，至少 15 分钟）
- **吸入中毒** → 转移至新鲜空气处，保持呼吸道通畅
- **食入中毒** → 催吐（**但腐蚀性物质严禁催吐**）
- **呼吸停止** → 立即**人工呼吸**

**严禁事项**：
- 救护人员**未佩戴防护装备**时**严禁盲目进入**现场施救（易造成施救者伤亡）
- **腐蚀性物质中毒严禁催吐**（会造成二次损伤）
</Callout>
