## 第一节 化工防火防爆基本要求

<h3 id="s1">1.1 防火防爆基本措施</h3>

<KeyPoint examWeight={3}>
**防火防爆的基本措施（围绕燃烧三要素）：**

| 措施类别 | 具体内容 |
|---|---|
| **控制可燃物** | ①用**不燃或难燃**物质取代可燃物质 ②**减少**可燃物储存量 ③防止可燃物**泄漏** |
| **控制助燃物** | ①**惰性介质保护**（加入 N₂、CO₂ 等，使氧含量降到极限氧浓度以下）②**密闭**操作 ③**通风**（防止可燃气体积聚） |
| **控制点火源** | ①严格**动火管理** ②使用**防爆电气设备** ③**防静电、防雷** ④禁止**摩擦撞击火花** ⑤控制**高温表面** |
| **控制爆炸极限** | 将可燃物浓度控制在**爆炸极限范围以外**（低于下限或高于上限） |
| **监测报警** | 设置**可燃气体检测报警仪**（报警值 LEL 的 10%~25%） |
| **安全装置** | **安全阀、爆破片、阻火器、防爆泄压装置** |
| **限制事故后果** | **防爆墙、泄压面积、安全距离** |
</KeyPoint>

<Callout type="tip">
**化工防火防爆的核心逻辑：**

**「断三要素」= 控可燃物 + 隔助燃物 + 去点火源**

**化工场景的特殊性**：
- 化工物料**70% 以上**易燃易爆，所以「控可燃物」难度大
- 多采用**惰性介质保护**（用氮封等）来「隔助燃物」
- 点火源控制最关键的是**防静电**（化工物料流动易产生静电）

**动火作业是化工企业最大的点火源风险**，因此动火管理是重中之重（详见第二章第五节）。
</Callout>

**工业建筑防火与防爆：**
①建筑物的**耐火等级**应符合要求 ②应设置**防爆泄压面积**（轻质屋盖、泄压门窗）③应设置**防火分隔**（防火墙、防火门）④**易燃易爆厂房**应单独设置，与其他建筑保持**防火间距** ⑤应设置**安全疏散通道**

## 第二节 主要化工防火防爆技术

<h3 id="s2">2.1 电气防火防爆安全技术</h3>

<KeyPoint examWeight={3}>
**爆炸危险区域划分（与技术科目一致）：**

**爆炸性气体、蒸气（3 个区域）：**
| 区域 | 定义 |
|---|---|
| **0 区** | 连续出现或长期出现爆炸性气体混合物的环境 |
| **1 区** | 在正常运行时可能出现爆炸性气体混合物的环境 |
| **2 区** | 在正常运行时不太可能出现，或即使出现也仅是短时存在的环境 |

**爆炸性粉尘、纤维（3 个区域）：20 区、21 区、22 区**

**防爆电气设备的选型原则：**
- **0 区**：只允许使用**本质安全型**电气设备
- **1 区**：可使用**隔爆型、增安型、本安型、正压型**等
- **2 区**：可使用**无火花型**等
</KeyPoint>

**化工防爆电气线路要求：**
①**1 区、2 区**的电气线路应穿**钢管**敷设 ②导线材质、截面、敷设方式均应符合防爆要求 ③应在**可能泄漏可燃气体、有毒气体的部位设置检测报警仪**

<h3>2.2 防静电与防雷安全技术</h3>

<KeyPoint examWeight={2}>
**防静电措施（化工重点）：**

| 措施 | 具体做法 |
|---|---|
| **静电接地** | 最常用措施。油罐、管道、装卸设备等应接地 |
| **限制流速** | 输送可燃液体时**限制流速**（防止高速流动产生静电） |
| **禁止喷溅** | 装卸时避免**高速喷溅**（应从底部进料） |
| **增湿** | 提高环境湿度，提高物体表面导电性 |
| **抗静电添加剂** | 加入添加剂降低液体电阻率 |
| **静电中和器** | 中和电荷 |
| **个体防护** | 操作人员穿**防静电工作服和工作鞋** |
| **禁用化纤** | 爆炸危险场所**不应使用化纤**材料的工具、抹布 |

**防雷措施：**
- **防直击雷**：装设**避雷针、避雷线、避雷带、避雷网**
- **防感应雷**：**接地、等电位联结**
- **防雷电侵入波**：装设**避雷器**
</KeyPoint>

<Callout type="warning">
**化工防静电的三个关键禁令：**

1. **限制流速** —— 可燃液体输送流速不得超过规定值
2. **禁止喷溅** —— 油品装卸应从**底部进料**，避免上部喷淋产生静电
3. **禁用化纤** —— 爆炸危险场所不使用化纤工具、抹布、工作服

**静电是化工企业最常见的点火源之一**，尤其在有可燃液体、气体的场所。
</Callout>

## 第三节 化工消防技术

<h3 id="s3">3.1 化工消防技术基本原理与消防设施</h3>

**化工消防技术基本原理：** 基于**灭火四原理** —— **隔离、窒息、冷却、化学抑制**

**化工常用消防设施：**

| 设施 | 适用场所 |
|---|---|
| **消防给水系统**（消火栓、消防水池） | 通用 |
| **泡沫灭火系统** | **油品、可燃液体**储罐区（最常用） |
| **干粉灭火系统** | 可燃气体、可燃液体、带电设备 |
| **气体灭火系统**（CO₂、七氟丙烷） | **精密仪器、计算机房、配电室** |
| **蒸汽灭火系统** | 化工装置区（用于扑救气体火灾） |
| **水喷淋系统** | 储罐区降温（防止储罐受热超压） |
| **火灾自动报警系统** | 通用 |

<Callout type="tip">
**化工场所消防设施的选择（高频）：**

- **油品储罐区** → **泡沫灭火系统**（泡沫覆盖窒息灭火）
- **化工装置区气体火灾** → **蒸汽灭火 / 干粉**
- **配电室、计算机房** → **气体灭火（CO₂/七氟丙烷）**
- **储罐降温** → **水喷淋系统**（防止储罐受热爆炸）

**关键概念**：化工储罐区火灾的**首要措施是冷却降温**（防止邻罐受热爆炸，引发连锁事故），而不是直接灭火。
</Callout>
