## 一、科目定位

《安全生产专业实务·化工安全》是中级注册安全工程师考试的**专业科目**，也是四科中**唯一有主观案例题**的科目。

| 项目 | 说明 |
|---|---|
| 考试时长 | 2.5 小时 |
| 满分 | 100 分 |
| 及格线 | 60 分 |
| 题型 | 客观题（单选、多选）+ 主观题（案例分析） |
| 专业方向 | 化工安全（7 个方向之一） |

**重要提示**：实务科目**必须选专业方向**，选错方向等于白考。如果你在**石油化工、炼化、油品销售、危化品仓储**等单位工作，就选**化工安全**。

## 三、7 章 31 节完整考点框架

### 第一章 化工安全生产概述（3 节）

- 第一节 化工企业安全生产特点 — 四大特点、70% 化学品有危害特性、"飞温"
- 第二节 化工生产过程安全 — **变更管理**（申请→评估→审批→实施→验收）
- 第三节 危险化学品基础知识 — 8 大类、**SDS 16 项内容**、安全标签

### 第二章 化工运行安全技术（8 节）⭐ 全科最高

- 第一节 **危险化工工艺及安全技术** — **18 种重点监管危险化工工艺**
- 第二节 工艺安全风险分析技术 — **HAZOP**（偏差=引导词+参数）、LOPA、SIL
- 第三节 化工装置开停工安全技术 — 加盲板隔离、升温升压控制
- 第四节 主要化工机械设备安全技术 — 安全阀 vs 爆破片
- 第五节 特殊作业环节安全技术 — 八大特殊作业（GB 30871）
- 第六节 化工过程控制和检测技术 — 可燃气体报警值 LEL 10%~25%、**SIS 独立于 DCS**
- 第七节 **危险化学品企业重大生产安全事故隐患判定** — "两重点一重大"
- 第八节 危险化学品重大危险源安全监控 — 紧急切断、SIS、三级监控

### 第三章 化工防火防爆安全技术（3 节）

- 第一节 化工防火防爆基本要求 — 断三要素
- 第二节 主要化工防火防爆技术 — 爆炸危险区域 0/1/2 区、防爆电气选型、防静电
- 第三节 化工消防技术 — 泡沫灭火（油品）、气体灭火（配电室）

### 第四章 化学品储运安全技术（9 节）

- 第一节 化工企业常用储存设施及安全附件 — **呼吸阀 + 阻火器**
- 第二节 罐区安全技术 — 防火堤容量、重大危险源罐区动火=特级
- 第三节 储罐安全操作与维护技术 — **储罐清洗 = 受限空间作业**、5~6 年检验
- 第四节 气柜安全技术 — 防泄漏、防超压、防回火
- 第五节 铁路装卸设施及作业安全技术
- 第六节 船舶装运安全技术
- 第七节 汽车装卸作业安全技术 — **静电接地顺序**（前先接地，后先拆管线）
- 第八节 油气回收安全技术 — 活性炭自燃风险
- 第九节 危险化学品包装安全技术 — 爆炸品包装双重保护

### 第五章 化工建设项目安全技术（2 节）⭐ 2025 年 25 分

- 第一节 **化工建设项目安全设计技术** — **本质安全三层次**、厂址选择、**防护目标三分类**
- 第二节 化工建设项目工程质量安全保障 — **压力试验 1.25 倍**、无损检测 RT/UT/MT/PT

### 第六章 化工事故应急管理及救援（4 节）

- 第一节 危险化学品事故类型与特点 — **多米诺效应**
- 第二节 化工事故应急准备与响应 — "先控制、后消灭"
- 第三节 化工企业现场应急处置方案与应急处置卡编制技术 — **应急处置卡**
- 第四节 化工事故应急演练与救援装备 — **缺氧必须用隔绝式呼吸器**

### 第七章 化工安全类案例（2 节）

- 第一节 重大危险源相关案例 — **500m 单元**、Σ(实际量/临界量)≥1、3 年评估
- 第二节 典型化工事故案例分析 — **事故等级 3/10/30**、GB 6441 二十类事故

## 四、必背高频数字速查（考前必看）

| 数字 | 含义 |
|---|---|
| **70%** | 化工化学品中具危害特性的比例 |
| **950℃ / -96℃** | 裂解炉出口温度 / 裂解气分离温度 |
| **10~30MPa、300℃** | 氨合成条件 |
| **1:3、300~450℃、15~30MPa** | 合成氨配比与条件 |
| **5%** | 氯气中含氢量爆炸临界值 |
| **90℃** | 三氯化氮分解爆炸温度 |
| **pH＜4.5** | 电解铵盐生成三氯化氮的条件 |
| **4%~75%** | 氢气爆炸极限 |
| **LEL 10%~25%** | 可燃气体报警值 |
| **30m / 15m / 10m** | 动火距可燃气 / 可燃液 / 溶剂清洗 |
| **19.5%~21%** | 受限空间氧含量 |
| **1.25 倍** | 液压试验压力（相对设计压力） |
| **500m** | 重大危险源单元边缘距离 |
| **3 年** | 重大危险源安全评估周期 |
| **3 / 10 / 30** | 事故等级死亡人数分界 |
| **1000万/5000万/1亿** | 事故等级经济损失分界 |

**建议的复习顺序（按分值从高到低）：**
