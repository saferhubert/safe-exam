## 第一节 化工企业常用储存设施及安全附件

<h3 id="s1">1.1 储罐的分类与选用</h3>

<KeyPoint examWeight={3}>
**储罐的分类：**

| 分类方式 | 类型 |
|---|---|
| **按结构** | **固定顶罐**、**浮顶罐**（内浮顶、外浮顶）、**球罐**、**卧式罐** |
| **按材质** | 钢制罐、非金属罐 |
| **按用途** | 原油罐、成品油罐、化工原料罐、液化气罐 |
| **按压力** | **常压罐**、**低压罐**、**压力罐**（球罐、卧式罐） |

**储罐的选用原则：**
- **易挥发、易挥发损失的油品** → **浮顶罐**（减少蒸发损失、降低火灾风险）
- **液化气体、高压介质** → **球罐**或**卧式罐**
- **小容量、临时储存** → **卧式罐**
- **大量储存、不易挥发** → **固定顶罐**
</KeyPoint>

**储罐的主要安全附件：**

| 安全附件 | 作用 |
|---|---|
| **呼吸阀** | 维持罐内压力平衡，防止罐体因超压或真空而损坏；同时减少油品蒸发损失 |
| **阻火器（防火器）** | 阻止外部火焰通过呼吸阀进入罐内，防止罐内油气被点燃 |
| **液位计** | 指示罐内液位，防止超装或抽空 |
| **温度计** | 监测罐内温度 |
| **压力表** | 监测罐内压力 |
| **高低液位报警装置** | 液位超限时报警 |
| **自动脱水器** | 自动排放罐底积水 |
| **泡沫发生器** | 火灾时产生泡沫灭火 |
| **喷淋降温装置** | 高温时喷水降温，防止储罐超压 |
| **静电接地装置** | 导走静电 |

<Callout type="warning">
**储罐安全附件的关键点：**

- **呼吸阀 + 阻火器** 是储罐最重要的安全附件组合：
  - **呼吸阀**：调压（防超压、防真空）
  - **阻火器**：防火（阻止外部火焰进入）
- **浮顶罐的浮盘**应能随液位升降，密封良好
- **储罐必须设置静电接地**（化工物料流动易产生静电）
- **必须设置高低液位报警**（防止超装溢出或抽空）

**高频考点**：**呼吸阀与阻火器必须配套使用**，且阻火器应安装在呼吸阀**外侧**（靠近外部环境一侧）。
</Callout>

## 第二节 罐区安全技术

<h3 id="s2">2.1 罐区安全管理</h3>

<KeyPoint examWeight={3}>
**罐区安全管理要点：**

1. **罐区应设置防火堤**（防止液体外流扩散）
   - 防火堤的有效容积应能容纳**最大储罐泄漏的液体量**
   - 防火堤内应设置**排水设施**（带水封，防止液体外流）
2. **罐区应设置防火间距**（罐与罐、罐与建筑物的距离）
3. **罐区应设置可燃气体检测报警装置**
4. **罐区应设置消防设施**（泡沫灭火系统、水喷淋）
5. **罐区应设置静电接地和防雷设施**
6. **罐区应严格管理动火作业**（重大危险源罐区防火堤内动火属**特级动火**）
7. **罐区应实行封闭管理**，严禁无关人员进入
8. **罐区应设置明显的安全警示标志**
</KeyPoint>

<Callout type="warning">
**罐区安全的三个核心要点：**

1. **防火堤** —— 有效容积应能容纳**最大储罐泄漏量**；排雨水设施应带**水封**
2. **防火间距** —— 罐与罐、罐与建筑之间必须符合《石油化工企业设计防火标准》（GB 50160）
3. **动火管理** —— **重大危险源罐区防火堤内的动火作业属「特级动火」**（最高级别）

**防火堤的作用**：万一储罐破裂，防火堤把液体限制在堤内，防止蔓延到其他罐区造成连锁事故。
</Callout>

## 第三节 储罐安全操作与维护技术

<h3 id="s3">3.1 储罐日常操作与检查维护</h3>

**储罐日常操作要点：**
①**严格控制液位**（防止超装溢出、抽空）②**控制收付油速度**（防止静电积聚）③**定期检查呼吸阀、阻火器**是否畅通 ④**定期检查液位计、温度计**是否准确 ⑤**定期排放罐底积水** ⑥**高温季节注意降温**

**储罐检查维护要点：**
①**日常检查**：液位、温度、压力、有无泄漏
②**定期检查**：罐体壁厚（腐蚀检测）、基础沉降、浮盘密封
③**年度检查**：全面检查安全附件
④**全面检验**：按规范周期进行（一般 **5-6 年**一次内部检验）

<h3>3.2 储罐清洗与防腐</h3>

<KeyPoint examWeight={3}>
**储罐清洗（2022 年考 8 分）：**

**清洗的必要性**：检修前、改变储存介质前、罐底沉渣过多影响计量时。

**清洗的安全要求：**
1. **清洗前必须进行置换**（用惰性气体或水置换油气）
2. **清洗前必须进行气体检测**（确认可燃气体浓度在安全范围内）
3. **清洗作业属于受限空间作业**，必须按受限空间作业管理
4. **必须办理作业许可**（受限空间作业票）
5. **必须设置监护人**（在罐外全程监护）
6. **作业人员必须佩戴个体防护装备**
7. **严禁使用明火、产生火花的工具**
8. **清洗后的废弃物必须妥善处理**

**储罐防腐：**
①**内防腐**：防止介质腐蚀罐壁（涂层、衬里）
②**外防腐**：防止大气环境腐蚀（涂层）
③**阴极保护**：电化学保护
④**定期检测壁厚**：监测腐蚀状况
</KeyPoint>

<Callout type="warning">
**储罐清洗的安全要点（高频）：**

**储罐清洗 = 受限空间作业 + 可能存在残留油气**

因此必须：
1. **先置换** → 2. **再检测** → 3. **后作业**
2. **必须办理受限空间作业票**
3. **监护人必须在罐外全程监护**
4. **严禁使用铁质工具**（防摩擦火花）
5. **作业人员必须正确佩戴防护装备**

**最危险的错误**：未置换合格就进罐清洗 → 残留油气遇火花爆炸。
</Callout>

## 第四节 气柜安全技术

<h3 id="s4">4.1 气柜的运行管理</h3>

**气柜的作用**：储存和调节可燃气体（如煤气、天然气）的供需平衡。

**气柜的主要类型：**
①**湿式气柜**（用水密封）②**干式气柜**（用油或干式密封）

**气柜运行管理要点：**
①**严格控制气柜的储存量**（防止过高或过低）
②**保持密封良好**（防止气体泄漏）
③**定期检查柜体、密封装置**
④**设置安全装置**（安全阀、放散管、阻火器）
⑤**设置可燃气体检测报警装置**
⑥**气柜周围应设置防护栏杆和警示标志**
⑦**气柜检修属于受限空间作业**，必须严格管理

<Callout type="tip">
**气柜安全的核心：防泄漏 + 防超压**

- **防泄漏** → 保持密封良好（湿式气柜的水封、干式气柜的油封）
- **防超压** → 设置**安全阀、放散管**（超压时自动放散）
- **防回火** → 设置**阻火器**（防止外部火焰进入气柜）

**气柜检修的安全要点**：必须先**置换合格**，再按**受限空间作业**管理。
</Callout>

## 第五节 装卸作业安全技术

<h3 id="s5">5.1 铁路装卸设施及作业安全技术</h3>

**铁路装卸安全要点：**
①**装卸栈台**应设置防护栏杆、安全梯 ②**铁路专用线**应远离人员密集区 ③**装卸前应检查**车辆状态、连接情况 ④**限制装卸流速**（防静电）⑤**必须有静电接地** ⑥**禁止在装卸过程中启动车辆**

<h3>5.2 船舶装运安全技术</h3>

**船舶装运安全要点：**
①**码头**应设置消防设施、防污设施 ②**装卸前应进行安全检查**（船舶、管线、阀门）③**限制装卸流速** ④**必须有可靠的静电接地** ⑤**设置警戒区**，禁止无关人员进入 ⑥**注意气象条件**（大风、雷电时禁止作业）

<h3 id="s7">5.3 汽车装卸作业安全技术</h3>

<KeyPoint examWeight={2}>
**汽车装卸（槽车）安全要点：**

1. **必须设置静电接地**（装卸前先接地，装卸后最后拆除）
2. **限制装卸流速**（一般不超过规定的安全流速）
3. **应采用底部装卸方式**（避免喷溅产生静电）
4. **严禁超装**（按规定的装载量）
5. **装卸过程中禁止启动车辆**
6. **驾押人员必须持证上岗**
7. **现场应配备灭火器材**
8. **设置警戒区**，无关人员禁止进入
</KeyPoint>

<Callout type="warning">
**汽车装卸的静电防护顺序（关键）：**

**装卸前**：先**接地** → 再**连接管线** → 再**开始装卸**
**装卸后**：先**停止装卸** → 再**拆除管线** → 最后**拆除接地**

**顺序不能错！** 如果先拆接地再拆管线，管线脱离时可能产生静电火花 → 引燃残余油气 → 爆炸。

**这是汽车装卸作业最容易被忽略的细节，也是高频考点。**
</Callout>

## 第六节 油气回收安全技术

<h3 id="s8">6.1 油气回收设施安全要求</h3>

**油气回收的意义**：减少油品蒸发损失，降低火灾爆炸风险，减少环境污染。

**油气回收的方法：**
①**吸附法**（活性炭吸附）②**吸收法** ③**冷凝法** ④**膜分离法** ⑤**组合工艺**

**油气回收设施的安全要求：**
①**回收装置应设置在安全区域** ②**必须设置阻火器**（防止火焰窜入）③**必须设置可燃气体检测报警** ④**必须设置静电接地** ⑤**回收系统的管道应良好接地** ⑥**吸附剂（如活性炭）应定期更换**（防止吸附热积聚引发火灾）⑦**回收装置应有防爆措施**

<Callout type="tip">
**油气回收的关键风险点：**

**活性炭吸附法**的风险：活性炭吸附油气时**放热**，若热量积聚可能导致**活性炭自燃**。

因此：
- **必须控温**
- **必须定期更换活性炭**
- **必须设置温度监测和报警**

**所有油气回收装置都必须设置阻火器**，防止外部火焰通过回收管道窜入油罐。
</Callout>

## 第九节 危险化学品包装安全技术

<h3 id="s9">9.1 危险化学品包装安全技术</h3>

<KeyPoint examWeight={2}>
**危险化学品包装的基本要求：**
1. **包装容器**应符合**国家标准**，能承受运输过程中的冲击和振动
2. **包装应牢固、密封**，防止泄漏
3. **包装上应有安全标签**（象形图、信号词、危险性说明）
4. **应根据危险化学品的性质**选择合适的包装材料和形式
5. **气孔设计和安装**应能防止内装物泄漏和外界杂质进入，排出的气体不得造成危险和污染环境
6. **复合包装**的内容器和外包装应**紧密贴合**，外包装不得有擦伤内容器的凸出物
7. **无论是新型包装、重复使用的包装，还是修理过的包装**，均应符合危险货物运输包装**性能试验**的要求

**盛装爆炸品包装的附加要求：**
①盛装**液体爆炸品**容器的封闭形式，应具有**防止渗漏的双重保护**
②除内包装能充分防止爆炸品与金属物接触外，**铁钉和其他没有防护涂料的金属部件不应穿透外包装**
③双重卷边接合的铁桶、金属桶或以金属做衬里的运输包装，应能防止爆炸物进入缝隙
④包装内的爆炸物质和物品，包括内容器，应**衬垫妥实**，在运输中不允许发生危险性移动
⑤盛装**对外部电磁辐射敏感的电引发装置**的爆炸物品，包装应具备**防止受外部电磁辐射影响**的功能
</KeyPoint>

<Callout type="warning">
**爆炸品包装的特殊要求（易考）：**

- **液体爆炸品** → **双重保护**防渗漏
- **金属部件** → 不应穿透外包装（除有防护涂料）
- **电引发装置** → 包装必须**防电磁辐射**
- **所有内容器** → 必须衬垫妥实，不允移动

**危险货物包装标志共 9 类**（与危险化学品 8 大类不同，包装标志是按运输要求划分的）。
</Callout>
