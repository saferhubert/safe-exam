## 第一节 危险化学品事故类型与特点

<h3 id="s1">1.1 危险化学品事故类型与特点</h3>

<KeyPoint examWeight={2}>
**危险化学品事故的主要类型：**

| 类型 | 特点 |
|---|---|
| **火灾** | 可燃液体、气体泄漏遇火源引发；可能引发连锁反应（多米诺效应） |
| **爆炸** | 可燃气体、蒸气、粉尘与空气形成爆炸性混合物遇火源；**破坏性最强** |
| **中毒** | 有毒气体、液体泄漏；**可能造成大范围人群中毒**，如液氯、液氨、硫化氢泄漏 |
| **泄漏** | 是火灾、爆炸、中毒的**前置原因**；可燃液体/气体储罐、管道、阀门泄漏最常见 |
| **灼伤** | 强酸、强碱等腐蚀性物质接触人体 |

**危险化学品事故的主要特点：**
①**突发性强**（难以预测）②**危害范围大**（毒气扩散、火灾蔓延）③**易引发次生灾害**（连锁反应）④**救援难度大**（需专业装备）⑤**社会影响大**（可能引发群体性事件）
</KeyPoint>

<Callout type="tip">
**化工厂「多米诺效应」是重点概念：**

**多米诺效应**：一起事故触发邻近装置或储罐发生第二起、第三起事故，形成连锁反应。

**典型案例**：储罐区一个罐着火 → 火焰辐射加热邻罐 → 邻罐超压破裂 → 引发更大范围火灾爆炸。

**防范多米诺效应的措施：**
- **足够的防火间距**
- **储罐喷淋降温**（防止邻罐受热）
- **防火堤**（防止液体外流）
- **及时疏散和隔离**
</Callout>

## 第二节 化工事故应急准备与响应

<h3 id="s2">2.1 应急准备与响应</h3>

<KeyPoint examWeight={3}>
**应急管理的四个阶段（与《安全生产管理》一致）：**
**预防 → 准备 → 响应 → 恢复**

**化工事故应急准备的核心内容：**
①**应急预案体系**（综合预案、专项预案、现场处置方案）②**应急组织与职责** ③**应急队伍**（专职/兼职救援队伍）④**应急物资装备** ⑤**应急通信保障** ⑥**应急培训与演练** ⑦**风险评估与应急资源调查**

**化工事故应急响应的关键步骤：**
1. **接警与报告**（立即报告，启动预案）
2. **响应分级**（根据事故严重程度确定响应级别）
3. **警戒与疏散**（划定警戒区，疏散人员）
4. **应急处置**（控制危险源、抢救人员、控制事态）
5. **应急支援**（请求外部救援力量）
6. **响应终止**（确认危险消除后终止）
7. **后期处置**（恢复生产、人员安置）
</KeyPoint>

<Callout type="warning">
**化工事故应急处置的首要原则：**

**「先控制、后消灭」** —— 首要任务是**控制危险源**（切断泄漏源、控制火势蔓延），而不是立即灭火。

**为什么？** 如果是**气体火灾**（如氢气、天然气），**盲目灭火会导致气体积聚，形成爆炸性混合物，一旦遇到火源会引发更严重的爆炸**。

因此，**气体火灾应在确保能切断气源的前提下才灭火**；不能切断气源时，应**保持稳定燃烧，同时冷却周围设备**。
</Callout>

## 第三节 化工企业现场应急处置方案与应急处置卡编制技术

<h3 id="s3">3.1 现场应急处置方案与应急处置卡</h3>

<KeyPoint examWeight={3}>
**应急处置卡（化工科目高频考点）：**

依据**《生产安全事故应急预案管理办法》（应急管理部令第 2 号）第十九条**：生产经营单位应当在编制应急预案的基础上，针对**工作场所、岗位的特点**，编制**简明、实用、有效**的应急处置卡。

**应急处置卡的分类（按《生产经营单位生产安全事故应急处置卡编制指南》YJ/T 32）：**

| 类型 | 主要内容 |
|---|---|
| **应急管理岗位** | ①明确应急管理岗位人员在**领导指挥、信息报告、应急处置**过程中采取的具体行动步骤<br/>②列出需要的应急救援队伍、专家、物资装备、医疗资源、交通运输、避难场所等应急资源<br/>③列出主要联系的部门、机构或人员及联系方式<br/>④根据紧急疏散需要，编制**疏散逃生应急处置卡**<br/>⑤其他注意事项 |
| **基层操作岗位** | ①简要描述岗位**主要风险类型及事故情景**<br/>②列出该岗位在**信息报告、应急响应和处置措施**方面的具体处置步骤，明确每个步骤的**责任人**<br/>③列出需要的人力、设备、物资等应急资源<br/>④列出「**谁预警、谁组织、谁处置、谁撤离**」等具体处置步骤，宜标绘**紧急避险路线图**<br/>⑤其他注意事项<br/>⑥根据需要，附上**装置工艺流程图** |

**应急处置卡的编制要求：**
- 应**简明、实用、有效**
- 应针对**重点岗位、人员**
- 应便于从业人员**携带**
- 应明确**具体的处置步骤和责任人**
</KeyPoint>

<Callout type="tip">
**应急处置卡 vs 应急预案的区别：**

- **应急预案** → **详细**的体系文件（综合/专项/现场处置方案）
- **应急处置卡** → **简明、便于携带**的**岗位行动卡**

**记忆锚点**：应急处置卡是「**口袋里的预案**」，核心是**让一线人员知道第一步该干什么**。

**基层操作岗位应急处置卡的关键四问**：**谁预警、谁组织、谁处置、谁撤离**
</Callout>

## 第四节 化工事故应急演练与救援装备

<h3 id="s4">4.1 应急演练与救援装备</h3>

<KeyPoint examWeight={3}>
**应急救援装备（高频考点）：**

| 装备类型 | 适用场景 |
|---|---|
| **过滤式防毒面具** | **氧含量 ≥19.5%** 且有毒气体浓度在允许范围内时使用。**不能用于缺氧环境** |
| **隔绝式呼吸防护装备（正压式空气呼吸器）** | **缺氧、高浓度有毒气体、紧急救援**时使用。**适用范围最广** |
| **防化服（全封闭）** | 强腐蚀、剧毒物质泄漏处置 |
| **防酸碱防护服** | 酸碱类物质作业 |
| **气体检测仪（便携式）** | 现场检测可燃气体、有毒气体浓度 |
| **堵漏器材** | 泄漏处置 |
| **洗消设备** | 人员、装备洗消 |

**应急演练的要求：**
①**每年至少组织一次**综合应急预案演练或现场处置方案演练
②应按**应急预案**的要求开展
③演练后应进行**评估**，形成**评估报告**
④应根据评估结果**修订完善应急预案**
</KeyPoint>

<Callout type="warning">
**呼吸防护装备的选择（最易考的区分点）：**

| 场景 | 应选用的装备 |
|---|---|
| 氧含量充足（≥19.5%）、有毒气体浓度不高 | **过滤式防毒面具** |
| **缺氧**环境 | **隔绝式呼吸防护装备**（绝不能过滤式！） |
| **高浓度有毒气体**、紧急救援 | **隔绝式呼吸防护装备** |
| 受限空间内缺氧或有毒 | **隔绝式呼吸防护装备 + 救生绳** |

**核心原则**：**缺氧环境下，过滤式防毒面具完全无效**（因为它需要空气通过滤毒罐，缺氧环境无氧可过滤）→ **必须用隔绝式**。

**这是最容易考倒人的点。**
</Callout>

## 本章小结

<Callout type="info">
**本章必背要点：**

1. **危险化学品事故类型**：火灾、爆炸、中毒、泄漏、灼伤
